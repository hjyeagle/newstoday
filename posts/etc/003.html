한줄 요약

그록 가입·기본 기능부터 캐릭터 일관성 유지 영상 연결법, 크롬 확장 'Grok Automation'으로 이미지·영상 생성을 손 안 대고 자동화하는 법까지 왕초보 눈높이로 보여 준다.

챕터별 요약

00:00 그록 자동화 하이라이트

  • 커피 한 잔 사이 수십 장 이미지가 자동으로 만들어지는 장면. 해외에선 화제인 그록 오토메이션을 국내에선 잘 안 쓴다며, 도구 사용법보다 '어디에 쓸지'가 핵심이라고 강조.

00:42 그록 AI와 친해지기

  • 구글 계정으로 가입, 슈퍼 그록 7일 무료 체험(카드 등록). 그대로 두면 월 30달러 결제 → 설정 > 구독 > 구독 관리에서 미리 취소.
  • 무료판도 대화 성능은 좋지만 이미지·영상 생성 횟수 제한이 큼.
  • 채팅·음성(말을 중간에 끊는 경향)·첨부·모드(자동/Fast/전문가/4.1 Thinking)·Imagine(6초/10초, 480·720p, 9:16 쇼츠/16:9 롱폼)·즐겨찾기 소개.
  • 추천 설정: 'Ctrl/Cmd+Enter로 제출' 켜기, '자동 비디오 생성' 끄기(이미지 첨부만 해도 생성돼 일일 한도 차감).

09:45 모르면 못 쓰는 그록 AI 기능

  • 아이디어는 채팅으로 그록에게 묻고, Imagine에서 이미지를 끝없이 생성 → 고르기 쉬움. '더 보기'는 새 변형, '이미지 편집'은 프롬프트 일부 수정.
  • 캐릭터 일관성: 영상 끝 프레임에서 우클릭 '동영상 프레임 복사' → 새 Imagine 창에 붙여넣고 이어서 생성하면 인물·동작이 자연스럽게 이어짐.
  • 영상 = 화면 + 소리. 그록에 노래 스타일·가사·캐릭터 유지 프롬프트·장면 프롬프트를 받아 노래는 Suno, 화면은 그록, 캡컷에서 입모양 맞추기.
  • 어색한 연결은 카메라 각도 변경(45° 측면 샷)·가만히 듣는 컷·회상 컷(걷는 뒷모습)으로 덮음. 대화형 영상은 타입캐스트·일레븐랩스 TTS로 목소리만 입히면 더 쉬움.

31:09 그록 자동화(Grok Automation) 활용법

  • 크롬 웹스토어에서 'Grok Automation' 확장 설치 → 그록 페이지에서만 동작.
  • 설정: 화면비, 프롬프트당 이미지/비디오 개수, 길이(6s / 6s 연결 = 앞 영상 마지막 프레임 자동 이어붙임), 재시도 횟수, 고화질 다운로드, 언어 한국어, '다운로드 전 저장 위치 확인' 끄기.
  • 프롬프트는 빈 줄로 구분해야 개별 작업이 됨. 텍스트→영상보다 텍스트→이미지→영상이 오류 적음. 프롬프트 지연으로 다운로드 충돌 방지.
  • 이미지 여러 장을 드래그해 순서대로 영상화, 파일명 앞 번호 + 이름 오름차순 정렬로 순서 관리.
  • 시연에서 '연결' 자동 이어붙이기는 여러 번 실패 — 프롬프트를 더 구체적으로 줘야 할 수도.

47:57 실제 활용 사례

  • 정보 채널용: 그록에 경제 대본(예: 부자 아빠 가난한 아빠) 작성 → 몇 줄씩 이미지 프롬프트로 변환 → 자동화로 이미지 대량 생성.
  • 이미지 100장 정도 뽑아 두고 필요한 1~2개만 영상화, 대본은 TTS로 음성화해 캡컷·프리미어에서 조합.

실무 포인트

  • 체험판은 결제 전에 구독 취소부터 해 두기.
  • '자동 비디오 생성'은 꺼서 일일 생성 한도 아끼기.
  • 장면 연결은 마지막 프레임 복사 또는 카메라 각도 전환으로 해결.
  • 자동화는 이미지 대량 생산에 가장 안정적, 영상 자동 연결은 아직 불안정.
  • 화면(그록)과 소리(Suno·TTS)를 따로 만들어 편집에서 합치는 구조로 생각하기.
