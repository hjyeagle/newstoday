빌더 조쉬_노션 및 도구

네이버 클로바에 돈 쓰지 마세요. 8분만에 무료 녹음 ➡️ 텍스트 무제한 변환 프로그램 만들어 쓰세요.

  • 등장인물 및 사용 도구: 빌더 조쉬(진행자)가 출연하며, 파이썬(Python 3.x), 커서 AI(Cursor IDE, 유료 요금제 활용), 오픈AI의 무료 위스퍼(Whisper) 엔진, 그리고 CustomTkinter/Tkinter 기반의 GUI 인터페이스를 사용합니다.
  • 비용 절감 수치: 기존 클로바노트 이용 시 발생하던 개인 월 2만 원, 팀 월 8만 원 상당의 구독 비용을 100% 무료로 대체할 수 있으며, 음성 데이터가 외부 서버로 유출되지 않는 완전한 로컬 보안 환경을 구축합니다.
  • 프로그램 제작 방법 및 절차:
    1. 공식 웹사이트(python.org)에서 파이썬을 다운로드하여 컴퓨터 백그라운드 환경에 설치합니다.
    2. 커서(Cursor) 프로그램 실행 후 새로운 프로젝트 폴더(예: 음성_추출기_샘플)를 생성하고 오픈합니다.
    3. 프롬프트에 핵심 조건 4가지를 지정하여 입력을 진행합니다: ① 파이썬 기반 프로그램 작성, ② 오픈AI의 무료 위스퍼(Whisper) 엔진 로컬 탑재, ③ 가상환경 및 필수 패키지 자동 세팅 명령어 포함, ④ 흑백 톤의 심플한 스크립트 확인 UI 구성.
    4. 커서 내부의 파이썬 재생 버튼을 눌러 데스크톱 앱을 구동하고, 위스퍼 모델 선택(기본 베이스) 및 오디오 파일을 지정하여 텍스트 추출을 진행합니다.
    5. 추가 기능 구현: 추출된 스크립트를 원하는 경로에 .txt 파일로 즉시 저장하는 버튼과 실시간 마이크 녹음 및 변환 기능을 프롬프트 추가 지시로 구현합니다.
  • 주의점: 위스퍼 모델 선택 시 성능이 뛰어난 라지(Large) 모델도 지원하지만, 초보자는 구동 속도와 리소스 효율성을 고려해 베이스(Base) 모델부터 테스트하는 것이 안전합니다.
  • 활용 팁: 프로그램 작성 시 커서에게 반드시 가상환경 필수 패키지 설치 명령어를 함께 포함하도록 지시해야 시스템 환경 충돌 없이 안정적인 데스크톱 유틸리티 앱이 완성됩니다.

  • 등장인물 및 사용 도구: 빌더 조쉬와 현성(노션다움 / 플로우테일러)이 출연하며, 노션 3.0(노션 에이전트), 제미나이(Gemini), 클로드(Claude), ChatGPT, 노션 데이터베이스, 노션 메일, 노션 캘린더, 슬랙(Slack), 메이크(Make)를 다룹니다.
  • 핵심 기능 및 변화: 이전 노션 AI와 달리 노션 3.0 업데이트 이후 AI가 사용자의 전체 데이터베이스(DB), 메일, 캘린더, 슬랙 대화록까지 직접 접근 및 읽기를 수행하여 나만의 맥락(Context)을 파악하는 에이전트 OS 역할을 수행합니다.
  • 구체적 구축 절차 및 방법:
    1. 초고속 DB 기획 및 생성: "도서관 DB 만들어줘" 프롬프트 입력 시 제목, 독서 상태, ISBN, 저자 등의 속성을 자동 생성합니다.
    2. 웹 검색 기반 데이터 자동 채우기: "한국 최신 책 10권 입력해 줘" 입력 시 외부 웹 검색을 거쳐 책 제목과 Yes24 구매 링크까지 DB 행(Row)으로 한꺼번에 입력합니다.
    3. 문서/DB 멘션 기반 보고서 자동화: DB 내 특정 책 페이지나 외부 링크를 @ 멘션하고 스페이스바를 눌러 20가지 템플릿 기반의 독서 보고서 및 서평을 자동 도출합니다.
    4. 데이터베이스 다이렉트 분석: 2023년 7월부터 축적된 193회차 오픈특강 신청자 DB를 다이렉트로 분석시켜 신규 대 재수강 비율 및 수강생들의 실질적 관심사(자동화, DB 구축 등)를 파악합니다.
  • 주요 수치: 노션 최신 키노트 기준 데이터베이스 처리 및 검색 속도가 3배 향상되었으며, 50% 수준인 특강 출석률을 파악하고 마케팅에 재활용하는 분석력을 보여줍니다.
  • 주의점: 대화형 AI와 달리 노션 AI는 실제 DB 구조와 데이터를 직접 수정하므로, 잘못 변경되었을 때를 대비해 하단의 '되돌리기' 버튼 위치와 기능을 숙지해야 합니다.
  • 활용 팁: 데이터가 파편화되어 있으면 AI가 읽지 못하므로 마크다운 형태와 정돈된 DB 구조로 사전 '구조화 작업'이 선행되어야 하며, 시스템 프롬프트(지침)를 상단에 사전 등록하여 개인화된 답변을 유도할 수 있습니다.

노션 CLI 이 영상 하나로 종결합니다. 무려 노션을 직접 만드는 분과 설명해드려요. (Eric Goldman, 노션 제품 리드)

  • 등장인물 및 사용 도구: 에릭 골드만(Eric Goldman, 노션 제품 리드, Sequin 공동창업자), 빌더 조쉬가 출연하며, 노션 CLI(ntn), 노션 워커스(Notion Workers), 클로드 코드(Claude Code), 깃허브/유튜브 API, 백엔드 샌드박스, TUI(Terminal User Interface), notion.dev를 다룹니다.
  • 인수 배경: 에릭 골드만이 설립한 데이터 실시간 동기화 플랫폼 세퀀(Sequin)이 노션에 인수(2024년 8월)되면서, 외부 서비스 데이터를 노션 DB로 연동하는 서버리스 실행 환경인 노션 워커스(Workers)와 CLI 도구로 재탄생했습니다.
  • 실전 연동 절차 (유튜브 통계 자동 동기화):
    1. 개발자 전용 사이트(notion.dev)에 접속하여 ntn CLI 설치 명령어를 복사 후 터미널에 실행합니다.
    2. 터미널에서 ntn workers new 명령어를 입력하고 프로젝트명(예: builderjosh-yt) 입력, git 및 패키지 초기화를 진행합니다.
    3. 클로드 코드 구동: ntn 내장 스킬이 클로드 코드에 워커 구조, SDK, sync 스킬 지침을 자동 주입합니다.
    4. 유튜브 채널 핸들, API 키, 동기화 주기(매일 1회 등)를 입력하면 AI가 동기화 코드를 작성하고 로컬 검증을 마칩니다.
    5. 배포: ntn login 후 ntn workers deploy를 실행하고, API 키 등 보안 인증서 정보는 ntn workers env push로 암호화하여 노션 인프라에 전송합니다.
    6. 결과: 노션 DB에 유튜브 영상 제목, 조회수, 썸네일, 재생 시간(초), 인게이지먼트 수치가 자동 수집·업데이트됩니다.
  • 주요 기능 및 수치: Progressive Disclosure(단계적 정보 노출)로 AI 토큰 소비를 대폭 절감하며, ntn workers tui 명령어로 실시간 동기화 건수(83개 비디오), 처리 주기(4.6초), 로그를 시각 모니터링합니다. 노션 사내 1,000명 직원이 3,000개 이상의 AI 에이전트를 운용 중입니다.
  • 주의점: API 키와 같은 보안 환경변수는 로컬에만 남겨두면 배포 후 서버 동작 시 오류가 발생하므로, 반드시 env push 명령어로 서버 환경변수에 업로드해야 합니다.
  • 활용 팁: 모든 개발 및 테스트는 컴퓨터 로컬 샌드박스에서 완전히 독립되어 실행되므로 노션 워크스페이스가 파손될 위험이 없으며, 기존 Zapier나 n8n 워크플로우 캡처 이미지를 클로드 코드에 주입하는 것만으로 워커 스크립트로 자동 변환이 가능합니다.

    1. 오퍼레이션 분리: 100% 정확도가 필요한 데이터 수집(스레드 API 연동 등)은 메이크(Make) 자동화로 처리하고, 문장 생성 및 맥락 파악은 노션 AI에 위임합니다.
    2. 5계층 아키텍처 설계: 헌법 역할을 하는 룰북(엔트리 포인트, 자가점검, 레벨 판단), 워크플로우를 정의하는 프로토콜, 실행 도구인 스킬, 양식을 담당하는 템플릿을 노션 관계형 DB로 상호 매핑합니다.
    3. 큐시트(Q-Sheet / 플랜 DB) 기획: AI가 명령을 받으면 즉시 실행하지 않고 실행 순서, 연관 스킬, 예상 산출물을 담은 큐시트를 먼저 기획·출력한 뒤 사용자 승인 하에 동작시킵니다.
    4. 5가지 워크플로우 모드: 작업 성격에 맞춰 리니어(선형), 멀티플렉스(다중 병렬), 하모니(다수결/가중치 집계), 계층 위임, 리파인 모드를 선택하여 에이전트를 실행합니다.
    5. 대글 자동화 실습: 스레드 원글 및 댓글 수십 개를 스크레이핑한 후 작성자 간 상호작용 횟수와 관계성(친한 동료, 일반 구독자 등)을 분석해 5가지 톤앤매너(캐주얼, 질문 유도 등)로 대글 초안을 도출합니다.
  • 주요 수치 및 자동화 성과: 프롬프트 지시 하나만으로 월간 스레드 리포트 문서를 자동 분석·생성하며 버전 관리(v1.0 등)를 수행하고, 새로운 스킬을 양산하는 '스킬 생성 스킬'까지 구축하여 에이전트 체계를 확장합니다.
  • 주의점: 시스템 프롬프트(지침)가 너무 길어지면 AI가 중간 지침을 스킵하는 할루시네이션이 발생하므로, 룰북과 엔트리 포인트 문서로 역할을 쪼개고 자가 점검 루프를 반드시 포함해야 합니다.
  • 활용 팁: 노션 AI 내 오케스트레이션 구동 시 AI가 스킬을 멋대로 선택하지 않도록 엔트리 포인트 문서에서 레벨별(Level 1~3) 작업을 엄격히 정의해 주는 것이 핵심입니다.
