빌더 조쉬_클로드 코드 활용

"만들었는데 안 팔린다"는 빌더들에게. 클로드 코드로 마케팅까지 끝내는 12단계 (김형태 대표, 데일리그로스)

  • 등장인물 및 사용 도구: 진행자(빌더 조쉬), 김형태 대표(데일리그로스 대표), 클로드 코드(Claude Code), 메타(Meta) 광고 API/MCP, 구글 애널리틱스(GA), 수파노바(SupaNova), 엑스펠드(Xfeld), GPT 이미지 2.0이 활용됩니다.
  • 마케팅 12단계 폴더 체계화 절차: 프로젝트 폴더 내 01~04번 전략 기획(3C 분석: 자사/경쟁사/고객, 브랜드 브리프), 05~08번 콘텐츠(카피라이팅, 스토리보드, 시드 자산), 09~12번 퍼포먼스 집행 및 대시보드 데이터 분석 단계로 폴더 구조를 사전에 세팅합니다.
  • 주요 수치: 15년 차 마케터(광고대행사 5년 + SK그룹 등 인하우스 9년 + 1인 대표), 메타 MCP 4월 공식 출시, 1인 오퍼레이션으로 3~4개 클라이언트 동시 운영.
  • 주의점:
    • 단순 제품 스펙이나 기능만 나열하는 자사 관점에서 벗어나 "0.25인치 드릴이 아닌 0.25인치 구멍"을 원하는 고객의 페인포인트와 문제 해결 관점으로 메시지를 전환해야 합니다.
    • 크론잡 기반의 100% 완전 자동화에만 맡기기보다, 퍼널 지표(CPM, CVR 등) 분석 후 광고를 중단하거나 새로 제작하는 최종 크리에이티브/전략적 의사결정은 마케터(인간)가 직접 판단해야 합니다.
  • 실전 활용 팁: 메타의 최신 안드로메다 알고리즘 업데이트에 발맞추어, 페인포인트 공감, 솔루션, 사회적 증거, CTA 등 다양한 페인포인트 앵글을 반영한 다각도 크리에이티브 소재를 미리 여러 개 양산해 두면 머신러닝이 최적 타겟을 스스로 찾아 집행 효율이 극대화됩니다.

(무료 소스 제공) 클로드 코드로 URL만 넣으면 10가지 콘텐츠가 동시에 쏟아집니다. 클로드 코드 멀티 에이전트

  • 등장인물 및 사용 도구: 빌더 조쉬(진행자), 클로드 코드(Claude Code 서브 에이전트 및 스킬), 커서(Cursor IDE), YTDLP(유튜브 자막 추출 라이브러리), 구글 AI 스튜디오 제미나이 3.0 프로 API(나노 바나나 프로), 로컬 위스퍼(Whisper 미디엄/라지 모델), 파이썬 스크립트가 사용됩니다.
  • 오케스트레이션 및 파이프라인 구축 절차:
    1. prompt.md 작성 시 클로드 코드 공식 가이드 문서(Docs)를 첨부하여 에이전트 설계 원칙을 준수시킵니다.
    2. 오케스트레이터 팀(플래너, 리뷰어/QA)이 유튜브 URL을 수집·분석하고 브리프(brief.md)를 작성해 전체 팀에 전달합니다.
    3. 텍스트 팀(뉴스레터, 블로그, 링크드인, 쓰레드 10개, 대본)과 비주얼 팀(나노 바나나 프로 연동 인스타 카드뉴스 5장, 썸네일), 쇼츠 편집 팀이 병렬로 작업을 동시 수행합니다.
    4. 리뷰어 에이전트가 산출물의 품질과 누락 여부를 검수(QA)하고 output/ 폴더로 리포트를 도출합니다.
  • 주요 수치: 도합 6만 구독자를 보유한 텍스트 크리에이터(조쉬), URL 1개 입력으로 10가지 멀티 플랫폼 콘텐츠 병렬 추출, 전체 구축 및 실행 소요 시간 10분 미만, 글자 크기 16pt 자막 적용.
  • 주의점:
    • API 키(구글 AI 스튜디오)는 유심칩처럼 보안 관리에 유의하여 환경변수나 지정 스크립트로 관리해야 합니다.
    • 타인의 유튜브 영상 무단 활용 시 저작권 이슈가 발생할 수 있으므로 본인 소유이거나 저작권 문제없는 영상 URL을 활용해야 합니다.
  • 실전 활용 팁: 뉴스레터 등 깊이 있는 글 작성이 필요한 에이전트 모델은 claude-3-5-sonnet 대신 claude-3-opus 모델로 지정하면 오타 없이 훨씬 충실하고 고품질의 아웃풋을 도출할 수 있습니다.

(오픈소스 제공) 클로드 코드로 긴 영상을 100% 자동으로 만들어보았습니다.｜Claude Code

  • 등장인물 및 사용 도구: 빌더 조쉬(진행자), 클로드 코드(Claude Code 서브 에이전트 & 스킬), 커서(Cursor IDE), 윔지컬(Whimsical), 제미나이 3.0 프로/나노 바나나 프로 API, 제미나이 2.5 플래시/프로 TTS API, 로컬 위스퍼 라지 V3(오픈AI), 파이썬 FFmpeg 라이브러리, 코트라(KOTRA) 손글씨체 TTF 폰트, 유튜브 오디오 보관함 BGM이 다뤄집니다.
  • 자동 롱폼 제작 파이프라인 절차:
    1. 비디오(디렉터) 에이전트가 영상 제작 파이프라인 전체를 오케스트레이션합니다.
    2. 작가 팀(리서치/대본 에이전트)이 쇼펜하우어 철학 명언 등 주제 자료를 수집·분석해 씬(Scene) 및 대본을 분할합니다.
    3. 스킬 팀 가동: 일러스트 팀(제미나이 3.0 프로), 음향 팀(제미나이 TTS API), 자막 팀(로컬 위스퍼 라지 V3), 영상 편집 팀(FFmpeg)이 각각 작동합니다.
    4. 파이썬 FFmpeg 스크립트로 일러스트, 나레이션 오디오, 자막, BGM, 트랜지션 효과를 합쳐 최종 오디오북 롱폼 영상으로 렌더링합니다.
  • 주요 수치: 15초 샘플 영상 생성 시 API/토큰 비용 약 100원~200원 소요, 10분~30분 롱폼 제작 시 약 5,000원~10,000원 과금 발생, 로컬 위스퍼 라지 V3 모델 구동을 위한 컴퓨터 저장 공간 약 2GB 필요, 구글 VEO 3 API 일일 호출 제한 약 10회.
  • 주의점:
    • 롱폼 영상은 대본 길이와 이미지/TTS API 호출 건수에 따라 토큰 및 API 비용이 급증하므로 짧은 샘플 테스트 후 단계적으로 접근해야 합니다.
    • 유튜브 플랫폼의 AI 자동 생성 영상 검열 정책이 강화되고 있으므로 100% 자동화 채널 업로드 시 가이드라인 준수에 주의가 필요합니다.
  • 실전 활용 팁: 눈누 사이트 등에서 제공되는 상업적 이용 가능한 무료 폰트(코트라 손글씨체 등)와 유튜브 오디오 보관함 무제한 BGM을 미리 assets/ 폴더에 세팅해 두면 저작권 리스크 없는 완성도 높은 오디오북 영상을 자동 생산할 수 있습니다.

[풀버전] 클로드코드로 고퀄리티 상세페이지 자동으로 만드는 방법 (기획, 카피라이팅, 디자인 모두)

  • 등장인물 및 사용 도구: 빌더 조쉬(진행자), 클로드 코드(Claude Code), 커서(Cursor IDE), 윔지컬 MCP, 제미나이 3.0 프로 API, 파이썬 스크립트(이미지 세로 병합), .env 환경변수 파일이 활용됩니다.
  • 100% 상세페이지 자동 생성 절차:
    1. 기획 팀(인테이크 수집 AI + 웹 리서치 에이전트)이 제품 핵심 정보와 소구점을 수집합니다.

    3. 디자인/개발 팀이 제미나이 3.0 프로 API를 호출하여 1,200x1,200px 규격의 조각 이미지 13개를 연속 생성합니다.
    4. 파이썬 스크립트가 13개 조각 이미지를 세로 순서대로 병합하여 고화질 PNG/PDF 상세페이지 파일로 파이프라인을 완성합니다.
  • 주요 수치: 외주 대행 시 100만 원~500만 원 호가하는 상세페이지 제작비 절감, 제미나이 3.0 프로 API 연동 기반 조각 이미지 13개 생성, 이미지 가로세로 1,200px 고정 규격 적용.
  • 주의점:
    • 제미나이 API 키 등 민감 정보는 코드나 프롬프트에 직접 노출하지 않고 .env 파일에 보관해야 하며, 구글 클라우드 콘솔 결제 계정 연동이 필수입니다.
    • 초기 생성 시 만화 톤이나 비율 왜곡이 발생할 수 있으므로 가로세로 1,200px 고정, 만화 톤 제거, 실사 모델 등장 비율 확대 등의 보정 지시를 반영해야 합니다.
  • 실전 활용 팁: 13단계 설득 구조 세일즈 라이팅 프레임워크(landing_plan.md)를 시스템 프롬프트로 사전 학습시키고 실제 화장품이나 유모차 등 샘플 레퍼런스 이미지를 함께 주입하면 상업적으로 즉시 활용 가능한 고품질 상세페이지가 자동 생성됩니다.

AI 전공한 개발자는 이렇게 클로드 코드를 씁니다. 사업+콘텐츠 모두 자동화합니다. (샘 호트만)

  • 등장인물 및 사용 도구: 진행자(빌더 조쉬), 샘 호트만(AI 엔지니어, 엔지니어의 시선 유튜버, 1인 에이전시 운영), 러버블(Lovable), n8n 자동화 도구, 패럼 AI(Fathom AI 노트테이커), 플라우드 노트, 제피어(Zapier), 클로드 코드(Claude Code), 리모션(Remotion 스킬), 일레븐랩스(ElevenLabs 커스텀 음성), 나노 바나나가 사용됩니다.
  • 사업 및 콘텐츠 자동화 파이프라인 절차:
    1. B2B 세일즈 미팅 투 프로덕트(Meeting-to-Product): 고객 문의 맥락으로 러버블(Lovable) POC 데모를 1차 빌드한 뒤 미팅을 진행합니다. 미팅 중 패럼 AI 전사록 웹훅을 n8n으로 받아 미팅 직후 제안서 PPT 초안을 자동 생성해 이메일로 즉시 발송합니다.
    2. n8n 패키지 기반 아웃바운드 영업: 마케팅/커머스 니치 시장에 정형화된 n8n 파이프라인 모듈을 수기로 제안하여 월 고정 구독(MRR) 매출을 창출합니다.
    3. 리모션(Remotion) 패키지 연동 쇼츠/모션 영상 자동화: 대본 입력 시 씬/문단 분할, 컨텍스트 윈도우 슬라이딩 기법으로 씬 코드(50개 이상) 및 나레이션 오디오, 자막, 모션 그래픽, 카드뉴스를 일괄 렌더링합니다.
  • 주요 수치: 1인 에이전시 비즈니스 23단계 로드맵 구축, 1인 개발/운영 기준 월 1,500만 원 매출 가이드, 10분 이상 롱폼 영상 제작 시 씬 50개 이상 병렬 생성, 클로드 코드 100달러~200달러 맥스 플랜 권장, 나노 바나나 이미지 1장당 $0.039, 10분 영상 제작비 약 2,000원~3,000원 소요.
  • 주의점:
    • 대량의 씬 코드를 병렬 생성하는 영상/캐러셀 작업 시 클로드 코드 20달러 기본 플랜은 토큰 한계에 부딪히므로 반드시 100달러~200달러 맥스 플랜을 사용해야 합니다.
    • 자동 생성 영상에서 시청자 이탈을 결정짓는 핵심 요소는 음성 전달력이므로 어설픈 오픈소스 TTS 대신 학습된 일레븐랩스 등 고품질 커스텀 음성을 써야 합니다.
  • 실전 활용 팁: 미팅 직후 제안서와 러버블 POC 데모를 수 분 내로 클라이언트에 전달하는 미팅 투 프로덕트(Meeting-to-Product) 파이프라인을 구축하면 B2B 세일즈 계약 수주 전환율을 비약적으로 올릴 수 있습니다.
