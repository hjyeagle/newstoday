(Lovable) 나만의 영어 단어장 사이트 만들기

  • 사용한 도구명: Lovable (lovable.dev), 자연어 프롬프트, 이미지 파일(스타일 참조용).
  • 핵심 내용 및 실습 절차:
    1. lovable.dev 웹사이트에 접속하여 구글 계정으로 로그인합니다.
    2. 대화창에 "영어 단어 학습에 도움이 되는 사이트를 만들어 주세요"라고 자연어 프롬프트를 입력합니다.
    3. Lovable AI 에이전트가 알아서 기획, 디자인, 백엔드/프론트엔드 코딩을 자율 수행하여 웹사이트를 빌드합니다.
    4. 첨부(attach) 기능으로 원하는 분위기의 이미지 파일(예: 필로소피 AI 브랜드 이미지)을 올리고 "이 이미지 느낌에 맞춰 디자인을 바꿔 줘"라고 요청합니다.
    5. AI 관련 어려운 단어(알고리즘, 신경망, 머신러닝 등) 뒤집기 단어장 카드를 추가 요청하고 Publish 버튼을 눌러 웹으로 배포합니다.
  • 주의점: 생성 도중 에러가 발생할 경우 당황하지 않고 Try to Fix 버튼을 누르면 AI 에이전트가 스스로 에러 원인을 파악하여 코드를 자동 수정합니다.
  • 활용 팁: 단순 챗봇 답변을 넘어서 코딩 지식 없이도 내가 공부하고 싶은 전문 분야(AI, 의학, 법률 등)의 전용 단어 학습 웹앱을 10분 만에 빌드하여 활용할 수 있습니다.

(Notebook LM) 영어 인터뷰 영상을 한국어 팟캐스트로 바꿔서 학습하는 시대

  • 사용한 도구명: Google NotebookLM, 유튜브 영어 인터뷰 영상(딥마인드 데미스 허사비스, 일론 머스크 등).
  • 핵심 내용 및 실습 절차:
    1. NotebookLM 접속 후 Create New로 새 프로젝트를 생성합니다.
    2. 공부하고 싶은 길고 어려운 영어 유튜브 영상의 주소(URL)를 소스로 등록합니다.
    3. 환경설정(Settings)에 들어가 출력 언어(Output Language)를 '한국어(Korean)'로 지정합니다.
    4. 커스터마이즈(Customize) 설정에서 "AI 입문자들을 위해 쉽게 대화하도록 집중해 주세요"라고 지침을 입력합니다.
    5. Generate를 클릭하여 두 명의 AI 호스트가 한국어로 재미있게 주고받는 5~10분 분량의 팟캐스트 오디오와 마인드맵을 도출합니다.
  • 주의점: 팟캐스트 생성 전에 세팅 메뉴에서 아웃풋 언어를 '한국어'로 사전에 바꾸어 놓지 않으면 영문 오디오가 생성되므로 사전 설정 확인이 필수적입니다.
  • 활용 팁: 1시간이 넘는 긴 해외 노벨상 수상자나 유명 CEO의 영문 인터뷰 영상을 일일이 다 시청하기 힘들 때, 이동 중이나 대중교통 이용 시 음성 팟캐스트로 편하게 한국어로 요약 청강할 수 있습니다.

(노트북 LM + Gemini 3 + Dynamic View) AI 시대에 영어 공부하는 법

  • 사용한 도구명: Google NotebookLM, Google Gemini 3, Dynamic View Labs (Gemini Tools).
  • 핵심 내용 및 실습 절차:
    1. NotebookLM에 쉬운 미국 여행 회화 유튜브 소스를 추가하고 기초 대화 스크립트를 작성합니다.
    2. Gemini 3 창을 열고 + 버튼의 Notebooks 탭을 눌러 해당 노트북 소스를 불러옵니다.
    3. 더 정교하고 다채로운 상황별 대화 스크립트와 어휘 학습 데이터를 Gemini 3로 고도화합니다.
    4. 생성된 대본을 복사하여 Gemini 툴스의 Dynamic View Labs 메뉴에 입력하고 실행합니다.
    5. 대화 문장, 한국어 해석 보기(Show Korean), 관련 그림 일러스트가 결합된 대화형 인터랙티브 웹 화면을 출력받아 공부합니다.
  • 주의점: Dynamic View 기능은 Gemini의 Tools 메뉴 내 Dynamic View Labs 항목이 활성화되어 있어야 동작합니다.
  • 활용 팁: 텍스트 대본을 단순히 눈으로 읽는 한계를 벗어나, 관련 삽화와 해석 버튼이 정돈된 앱 형태의 다이나믹 웹 화면으로 전환하여 실전 회화 롤플레이를 즐겁게 몰입할 수 있습니다.

(필로소피 AI 스터디) AI를 활용한 영어 공부법

  • 사용한 도구명: AI 기반 영어 학습 프레임워크, 네이버 카페 (필로소피 AI 교육).
  • 핵심 내용 및 실습 절차:
    1. 영어를 영어로 받아들이는 직관적 습관과 AI 기술을 결합하는 핵심 학습 방향성을 정립합니다.
    2. AI 스터디에 참여한 후 네이버 카페 'AI로 영어 공부하기' 게시판에 학습 일기를 개설합니다.
    3. 거창한 분량이 아니더라도 매일 1~2분씩 AI 오디오 듣기/읽기를 수행하고 카페에 짧은 인증글을 작성합니다.
    4. 한글 번역 습관을 배제하고 AI 튜터를 통해 영어를 있는 그대로 체화하는 루틴을 유지합니다.
    5. 스터디 대관료를 제외한 남은 비용을 근육병 환우 지원 재단 등에 전액 기부하며 함께 성장하는 학습 모임을 이어갑니다.
  • 주의점: 처음부터 무리하게 대량의 학습 목표를 잡기보다는 매일 1~2분이라도 꾸준히 실행하고 카페에 인증을 남기는 지속성이 핵심입니다.
  • 활용 팁: 혼자 공부할 때 빠지기 쉬운 중도 포기를 방지하기 위해 커뮤니티 게시판 인증 시스템과 AI 파트너를 결합하여 공부 습관을 정착시킵니다.

[Claude Code] 나만의 영어 학습 사이트 만들기

  • 사용한 도구명: Claude Code (CLI Agent), Windows PowerShell / WSL, GitHub, Cloudflare Pages.
  • 핵심 내용 및 실습 절차:
    1. 파워셸(WSL) 환경에서 claude 명령어를 입력해 클로드 코딩 에이전트를 구동합니다.
    2. "영어 단어 학습 카드 게임(학습, 퀴즈, 랜덤 모드) 웹사이트 HTML, CSS, JS 파일을 만들어 줘"라고 자연어 명령을 내립니다.
    3. 클로드 코드가 지정 폴더에 필요한 웹 코드를 알아서 생성하고 에러를 자율 수정합니다.
    4. 메인 HTML 파일의 이름을 index.html로 변경한 후 GitHub 레포지토리에 커밋 및 업로드합니다.
    5. Cloudflare Pages 서비스에 가입하여 해당 GitHub 저장소를 지정하고 클릭 한 번으로 무료 퍼블릭 웹 앱을 배포합니다.
  • 주의점: Cloudflare Pages 등 웹 호스팅 서비스로 배포할 때 메인 파일명이 index.html로 지정되어 있지 않으면 페이지 로딩 오류가 발생합니다.
  • 활용 팁: 웹 챗봇에서 코드를 복사해서 파이썬 파일에 옮겨 넣는 번거로운 과정 없이, CLI 에이전트가 내 로컬 폴더에 알아서 단어장 웹 파일을 완성해 주므로 수 분 만에 나만의 영어 게임 사이트를 배포할 수 있습니다.

[Notebook LM] MIT 수업을 한국어로 바꿔듣는 시대! (한국어 비디오 기능 지원)

  • 사용한 도구명: Google NotebookLM (한국어 비디오 오버뷰 지원), MIT OpenCourseWare 유튜브 영문 강의.
  • 핵심 내용 및 실습 절차:
    1. MIT 물리학 양자역학 등 공부하고 싶은 해외 명문대 영어 강의의 브라우저 상단 주소를 복사합니다.
    2. NotebookLM을 열고 소스 추가에서 유튜브 URL을 붙여넣습니다.
    3. 우측 비디오 오버뷰(Video Overview)의 점 세 개 메뉴(Customize)에서 언어를 '한국어'로 설정합니다.
    4. "학생들이 쉽게 이해할 수 있는 수준의 비디오로 설명해 주세요"라고 요구사항을 적고 Generate를 누릅니다.
    5. 17분 분량의 원본 전문 영문 강의가 5분 분량의 시각 슬라이드가 결합된 한국어 해설 비디오 및 요약 자산으로 전환된 것을 확인하고 학습합니다.
  • 주의점: 소스 추가 시 유튜브 하단의 짧은 공유 링크 대신 브라우저 주소창의 전체 URL 경로를 입력해야 인식 에러가 없습니다.
  • 활용 팁: 일반 인터넷 블로그의 가벼운 요약글이 아닌, 실제 MIT 교수님의 검증된 원본 강의 데이터를 토대로 정확한 한국어 비디오 해설 자산을 만들어 깊이 있게 공부할 수 있습니다.

AI 영영 사전으로 CNN 영문 뉴스 읽기 #01 (MIT new research)

  • 사용한 도구명: AWS PartyRock 기반 맞춤형 영영사전 앱, CNN 영문 기사.
  • 핵심 내용 및 실습 절차:
    1. AWS PartyRock으로 제작한 영영사전 앱에 접속하여 사용자 영어 레벨(A1~C2 중 선택, 예: A1)을 설정합니다.
    2. CNN 뉴스 기사(MIT AI 노동시장 연구 등)를 읽으며 모르는 단어(anxiety, frenzy, adoption 등)를 영영사전에 입력합니다.
    3. 사전 앱이 사용자의 A1 눈높이에 맞춰 영어 뜻, 품사, 발음, 영문 동의어(synonym), 예문을 안내합니다.
    4. 단어 밑에 한국어 뜻을 적는 대신 영문 동의어를 적거나 직관적인 소그림을 그려 노트에 정돈합니다.
    5. 한국어 번역 과정을 거치지 않고 영어를 영어 그대로 받아들이는 힘을 뺀 영문 리피팅 독해를 진행합니다.
  • 주의점: 단어 밑에 한국어 뜻을 기입하면 영어를 한국어로 변환하려는 오랫동안 형성된 번역 습관이 다시 작동하므로, 반드시 영문 동의어나 그림 표기 원칙을 지켜야 합니다.
  • 활용 팁: 개인의 영어 실력 레벨(A1 초보 ~ C2 고급)을 선택할 수 있어, 초보자도 난해한 CNN 뉴스 어휘를 자기 수준에 맞는 쉬운 영문 정의로 풀어서 부담 없이 독파할 수 있습니다.

AI로 외국어 공부하는 구체적인 방법 (실습 포함 38분 영상)

  • 사용한 도구명: StoryWeaver / Project Gutenberg (무료 PDF), Claude/ChatGPT (외국어 학습 에이전트 팀), ElevenLabs / Google AI Studio (TTS 오디오), Gemini (음성 대화).
  • 핵심 내용 및 실습 절차:
    1. StoryWeaver 등에서 무료 동화책 PDF(영어, 스페인어 등)를 다운로드합니다.
    2. 외국어 학습 에이전트 지침이 세팅된 AI에 PDF를 첨부하여 원문, 번역, 발음, 동의어가 정돈된 교재 자료를 도출하고 출력합니다.
    3. 교재에 한국어 뜻 대신 그림을 그리거나 영문 동의어를 적어 학습 준비를 마칩니다.
    4. ElevenLabs 또는 Google AI Studio에서 원문 텍스트를 고품질 MP3 오디오 파일로 변환하여 매일 밤 힘을 빼고 들으며 머릿속으로 상황을 그립니다.
    5. 제미나이 앱의 음성 모드를 열고 한국인 선생님 페르소나를 부여해 한국어와 외국어를 섞어가며 음성 회화 롤플레이를 실습합니다.
    6. Google AI Studio로 해당 교재 기반의 학습 웹앱 및 스토리북을 직접 창작해 내며 학습을 완결합니다.
  • 주의점: 오디오를 들을 때 한 문장씩 한국어로 번역하려 힘을 주지 말고, 동화책 스토리를 머릿속 그림으로 그리며 원어민 소리를 그대로 수용하는 힘 뺀 리스닝이 필수적입니다.
  • 활용 팁: 단순 읽기를 넘어 AI 오디오 제작, 음성 회화 롤플레이, 학습 웹앱 및 스토리북 창작까지 이어지는 올인원 외국어 체화 시스템을 구축할 수 있습니다.

Chat GPT로 비용 없이 영어 회화 공부하기!

  • 사용한 도구명: ChatGPT 모바일 앱 (음성 기능 / 3.5 및 4o 지원), 이메일 및 PC 화면.
  • 핵심 내용 및 실습 절차:
    1. 스마트폰에 공식 ChatGPT 앱을 설치하고 로그인합니다.
    2. 대화창 하단의 헤드폰 아이콘을 눌러 음성 대화 모드로 들어갑니다.
    3. "햄버거 가게/공항 상황에서 롤플레이 회화 연습을 하고 싶어. 대본을 쉬운 영어로 짜 줘"라고 음성으로 요구합니다.
    4. 대화가 끝나면 대화 텍스트가 대화창에 자동으로 기록된 것을 확인합니다.
    5. 스크립트를 내 이메일로 보내 컴퓨터 화면에 띄워두고 보면서, 다시 음성 모드를 켜서 롤플레이 대화를 진행합니다.
  • 주의점: 음성 대화 진행 중에는 대화창의 스크립트 텍스트가 보이지 않으므로, 영어 초보자는 대본을 컴퓨터나 종이에 따로 띄워두고 보면서 대화하는 것이 훨씬 수월합니다.
  • 활용 팁: 대본을 보며 대화하기가 익숙해지면 대본 없이 즉흥 대화를 시도하거나, 대화 내용을 출력하여 혼자서 소리 내어 반복 읽는 연습으로 확장할 수 있습니다.

  • 활용 팁: 한 서비스 안에서 영어뿐만 아니라 일본어, 독일어 등 다양한 외국어의 상황별 맞춤 오디오 파일을 무료로 원하는 만큼 제작해 반복 청강할 수 있습니다.

8. 드디어 Gemini 3 출시! 영어 학습 앱 만들어보기

  • 핵심 요약 및 개요: Google AI Studio에서 새로 출시된 Gemini 3 Pro Preview 모델의 빌드(Build) 기능을 구동하고 간단한 한 줄 요청만으로 롤플레이 회화, 문법 교정, 수준별 리딩 클럽 스토리가 결합된 영어 학습 웹앱을 순식간에 제작하고 배포하는 가이드입니다.
  • 사용한 도구명: Google AI Studio (Gemini 3 Pro Preview / Build Feature), Deploy App.
  • 실습 절차:
    1. Google AI Studio에 접속하여 Build 메뉴를 선택하고 모델을 Gemini 3 Pro Preview로 지정합니다.
    2. 프롬프트 입력창에 "영어 공부에 도움이 될 만한 기능이 풍부한 앱을 만들어 줘"라고 요청합니다.
    3. Gemini 3가 회화 롤플레이, 문법 피드백, 레벨별 스토리 생성이 포함된 'FluentFlow' 웹앱 코드를 자율 생성합니다.
    4. 우측 상단의 Deploy App 버튼을 눌러 온라인에 퍼블릭 웹사이트 주소(URL)를 배포합니다.
    5. 배포된 웹 주소로 진입하여 레벨별 스토리 생성, 어휘 퀴즈, 실시간 문법 교정 기능을 직접 사용합니다.
  • 주의점: Gemini 3 Pro Preview 모델은 무료 사용자도 구동 가능하지만 일일 호출 한도가 적용되므로 작업 배분에 유의해야 합니다.
  • 활용 팁: 세부 기능을 일일이 지시하지 않아도 AI가 알아서 어휘 정리 및 퀴즈까지 포함된 종합 영어 학습 플랫폼을 완성해 주므로 교안 웹사이트 제작 시간을 크게 줄여줍니다.

9. 딥시크 deep seek API 쉬운 활용법 (나만의 영어 선생님 만들기)

  • 핵심 요약 및 개요: 딥시크(DeepSeek) API 키를 발급받고 Cursor AI, 파이썬, GitHub 및 Streamlit Cloud를 연동하여, 평소에는 영어로 회화를 나누다가 문법을 질문하면 한국어로 쉽게 해설해 주는 나만의 영어 선생님 웹사이트를 배포·구동합니다.
  • 사용한 도구명: DeepSeek API Key, Cursor AI, Python, GitHub, Streamlit Cloud.
  • 실습 절차:
    1. 딥시크 플랫폼(platform.deepseek.com)에서 API 키를 생성하고 소액 충전을 완료합니다.
    2. Cursor AI를 켜고 딥시크 멀티 라운드 컨버세이션 API 문서를 참고하도록 주소를 입력합니다.
    3. 파이썬 코드(api.py), 한국어 문법 해설 지침이 담긴 시스템 프롬프트(instruction.txt), requirements.txt 파일을 자동 작성시킵니다.
    4. 파이썬 코드와 라이브러리 안내 파일 두 개를 GitHub 새 레포지토리에 올립니다.
    5. Streamlit Cloud에 접속하여 저장소를 연동 배포하고 웹 UI에서 딥시크 API 키를 입력해 영어 회화 및 문법 공부를 진행합니다.
  • 주의점: GitHub에 올리는 라이브러리 안내 파일명(requirements.txt)의 스펠링이 정확해야 Streamlit Cloud 배포 시 설치 오류가 나지 않습니다.
  • 활용 팁: 자유 대화를 나누다가 이해가 안 되는 문법이나 관용구가 나올 때 "관계대명사에 대해 알려줘"와 같이 질문하면 지정한 시스템 프롬프트에 따라 친절한 한국어 문법 해설을 받아볼 수 있습니다.

10. 영어 원서, 영어 회화 공부 with MS Copilot AI

  • 핵심 요약 및 개요: MS Copilot 앱의 GPT-Vision 및 실시간 음성 기능을 활용하여, 읽고자 하는 영어 원서 페이지를 카메라로 촬영해 올리고 AI와 화면의 영문 텍스트를 함께 보며 음성 대화로 원서 내용을 토론하는 스피킹 학습법입니다.
  • 사용한 도구명: MS Copilot App (iOS/Android/Web), GPT-4, GPT-Vision, 음성 대화 기능.
  • 실습 절차:
    1. 스마트폰에 MS Copilot 앱을 설치하고 프로필 설정에서 스피치 언어를 'English'로 변경합니다.
    2. 카메라 아이콘을 눌러 읽고자 하는 영어 원서책(예: 부자 아빠 가난한 아빠)의 한 페이지를 촬영해 첨부합니다.
    3. GPT-Vision이 원서 내용을 읽고 분석하여 핵심 요약 및 관련 출처를 안내합니다.
    4. 마이크 버튼을 눌러 "Can you tell me about this book?" 또는 "Let's discuss about this book"이라 음성으로 질문합니다.
    5. AI의 답변 문장이 화면에 실시간 영문 텍스트로 표기되는 것을 확인하며 음성 대화로 책 내용에 대한 프리토킹을 이어나갑니다.
  • 주의점: Copilot 앱 내 롤플레이 스크립트 생성 요청은 정책상 거부될 수 있으므로, 책 주체 토론 방식을 활용하거나 Bing 앱 내부 Copilot을 연동해야 합니다.
  • 활용 팁: AI가 말하는 대화 문장이 화면에 문자 텍스트로 동시에 지원되므로, 듣기 오디오와 눈으로 읽는 글자를 함께 점검하면서 어휘와 회화 표현을 더욱 정확하게 습득할 수 있습니다.
