1. (Channels) 길에서 디스코드 앱으로 클로드 코드에게 일을 시키는 시대

  • 핵심 요약 및 개요: 모바일 디스코드 앱이나 텔레그램을 통해 외부에서도 Claude Code에 명령을 내려 원격으로 개발 작업을 진행할 수 있는 Channels MCP 연동법을 설명합니다.
  • 사용한 도구명: Claude Code, Discord App / Bot, Claude Code Channels MCP Server, Node.js (bun).
  • 실습 절차:
    1. 디스코드 개발자 포털에서 신규 애플리케이션 및 봇을 생성한 뒤 토큰을 발급받아 메모장에 저장합니다.
    2. 봇 권한(메시지 전송, 채널 보기 등)과 Message Content Intent를 활성화하고, 생성된 URL로 디스코드 개인 서버에 봇을 초대합니다.
    3. 클로드 코드 터미널에서 디스코드 플러그인 설치 및 디스코드 토큰 등록 명령어를 실행합니다.
    4. 터미널에서 claude channels 명령으로 채널 모드를 켜고 디스코드 봇에게 DM을 보내 6자리 페어링 코드를 받아 페어링을 완료합니다.
    5. 정책을 all로 설정한 후 모바일 디스코드 앱에서 봇에게 자연어로 웹 개발이나 코드 수정을 지시합니다.
  • 주의점: 디스코드 봇 설정 시 Message Content Intent 항목을 반드시 활성화해야 메시지를 정상 수신하며, 채널 모드가 실행된 상태의 터미널 세션이 유효해야 모바일에서 원격 제어가 가능합니다.
  • 활용 팁: 외부 이동 중에도 모바일 디스코드 앱을 이용해 웹사이트 생성, 버그 수정, 작업 권한 승인(Allow) 등을 실시간으로 처리할 수 있습니다.

2. (Sittch + Nano Banana) 나노 바나나가 웹사이트 디자인까지 하는 시대!

  • 핵심 요약 및 개요: AI 코딩 도구의 시각적 디자인 한계를 극복하기 위해 구글 스티치(Stitch)의 나노 바나나(Nano Banana) 모델로 디자인을 재구성한 뒤, 이를 코드로 변환하여 웹사이트에 적용하는 워크플로우를 다룹니다.
  • 사용한 도구명: Google Stitch, Nano Banana (Gemini 2.5 Flash Image / Redesign 모델), Gemini 3.0 Pro, AntiGravity, GitHub, Netlify.
  • 실습 절차:
    1. AntiGravity 또는 Claude Code로 기본 웹사이트를 코딩하고 Netlify로 1차 배포합니다.
    2. 1차 배포된 웹사이트 화면을 캡처하여 구글 스티치에 업로드합니다.
    3. 스티치의 모델을 Redesign(나노 바나나)으로 설정한 뒤 감각적이고 전문적인 디자인 재구성을 요청합니다.
    4. 생성된 이미지 시안을 다운로드한 후, 스티치 모델을 Gemini 3.0 Pro로 바꾸고 다운로드한 이미지를 첨부하여 HTML 코드로 변환을 요청합니다.
    5. 추출된 HTML 코드를 AntiGravity 프로젝트에 복사·적용하여 디자인을 업데이트하고 GitHub 연동을 통해 Netlify에 자동 반영합니다.
  • 주의점: 나노 바나나 모델은 순수 디자인 이미지 생성용이므로 코드 직접 추출이 불가능합니다. 반드시 Gemini 3.0 Pro 모델로 전환한 뒤 이미지를 코드로 변환하는 2단계 과정을 거쳐야 합니다.
  • 활용 팁: 디자인 전용 AI와 코드 생성 AI의 역할을 분리하여 조합하면 한 줄의 코드 직접 작성 없이도 수준 높은 UI/UX 디자인의 웹사이트를 제작할 수 있습니다.

3. (Stitch + Google AI Studio) 디자인, 로직 구현, 배포까지! 이제는 필요한 툴은 직접 만들 수 있습니다!

  • 핵심 요약 및 개요: 구글 스티치로 프론트엔드 UI 디자인을 잡고, 이를 구글 AI 스튜디오로 내보내 실제 백엔드 로직과 대시보드 기능을 손쉽게 결합·배포하는 제작법을 다룹니다.
  • 사용한 도구명: Google Stitch, Google AI Studio, Claude Projects (프롬프트 제작팀).
  • 실습 절차:
    1. Claude Projects에 프롬프트 지침을 설정하고 원하는 서비스(예: AI 구독 관리자 대시보드) 아이디어를 대화로 전달하여 스티치 및 AI 스튜디오용 전용 프롬프트를 생성합니다.
    2. 구글 스티치에 스티치용 프롬프트를 입력하여 시각적 대시보드 UI 디자인을 생성합니다.
    3. 스티치의 Export to AI Studio 기능을 사용하여 디자인과 HTML 구조를 구글 AI 스튜디오로 바로 내보냅니다.
    4. 구글 AI 스튜디오에서 백엔드 기능 프롬프트를 추가 입력하여 실제 동작하는 로직(Gemini API 키 입력, 서비스 추천 및 구독 분석 등)을 결합합니다.
    5. 우측 상단의 Deploy App 로켓 버튼을 클릭하여 웹사이트 배포 URL을 생성하고 즉시 테스트합니다.
  • 주의점: AI 스튜디오에서 Gemini API 키가 필요한 기능을 구현할 때 사용자의 개인 API 키가 브라우저 로컬 저장소에만 저장되도록 설계해야 비용 남용 및 보안 문제를 방지할 수 있습니다.
  • 활용 팁: 디자인 툴(Stitch)과 로직·배포 툴(Google AI Studio) 간의 원클릭 연동 기능을 활용하면 코딩 지식이 없는 사용자도 자신에게 필요한 개인 맞춤형 대시보드 웹앱을 직접 만들 수 있습니다.

4. (입문자용) 클로드 코드로 웹사이트 만들고 배포하기!

  • 핵심 요약 및 개요: 코딩 초보자를 위한 과정으로, 클로드 코드로 생성한 HTML 웹사이트를 GitHub와 Netlify, 그리고 커스텀 도메인까지 연동하여 실제 서비스로 완성하는 배포 워크플로우입니다.
  • 사용한 도구명: Claude Code, GitHub, Netlify, 가비아 (Gabia).
  • 실습 절차:
    1. 클로드 코드를 실행하고 프롬프트를 입력하여 프로젝트 폴더 내 랜딩 페이지 HTML 파일(index.html)을 생성합니다.
    2. GitHub에 접속하여 새 저장소(Repository)를 만들고 uploading an existing file 옵션으로 HTML 파일을 업로드 및 커밋합니다.
    3. Netlify에 GitHub 계정으로 연동 로그인한 뒤 Import an existing project로 해당 저장소를 선택해 즉시 배포합니다.
    4. 가비아 등 도메인 구매 사이트에서 원하는 웹 주소를 구매합니다.
    5. Netlify의 Domain Management 설정에서 구매한 커스텀 도메인을 등록하고 DNS 연결을 마무리합니다.
  • 주의점: 아무리 코드를 잘 짜도 실제 도메인과 서빙 환경에 배포하지 않으면 활용할 수 없으므로, 생성부터 배포까지 연결되는 전 과정을 파악하는 것이 가장 중요합니다.
  • 활용 팁: 프로젝트 시작 시 클로드 코드에게 먼저 전용 작업 폴더를 생성하게 한 뒤 그 안에 index.html 파일을 만들도록 지시하면 파일 관리가 훨씬 정돈됩니다.

5. [클로드 코드] Git Hub MCP 서버 추가 + Agent 기능 사용법

  • 핵심 요약 및 개요: 클로드 코드에 Docker 기반 GitHub MCP 서버를 설치하고, 개발·테스트·보안·배포 등 역할별 서브 에이전트 팀을 구성하여 개발부터 배포까지 자동화하는 방법입니다.
  • 사용한 도구명: Claude Code (Sub-Agents / Agent Team), Docker Desktop, GitHub MCP Server, PowerShell / WSL2.
  • 실습 절차:
    1. GitHub 세팅에서 Personal Access Token (Classic)을 발급받아 스코프 권한을 설정하고 저장합니다.
    2. PowerShell을 관리자 권한으로 열어 WSL2를 활성화하고, Docker Desktop을 설치 및 실행합니다.
    3. 발급받은 토큰을 포함한 Docker 실행 명령어를 CLI에 입력하여 클로드 코드에 GitHub MCP 서버를 연동합니다.
    4. 클로드 코드 내에서 /agents 명령을 통해 역할별 서브 에이전트(미노: 개발, 준노: 테스트, 진수: 보안, 유민: GitHub 배포 등)를 생성합니다.
    5. 에이전트 팀에 작업을 부여하여 앱 개발부터 코드 검토, GitHub 저장소 자동 생성 및 GitHub Pages 배포까지 순차 진행합니다.
  • 주의점: Docker 설치 시 Use the WSL 2 based engine 옵션이 반드시 체크되어 있어야 하며, 토큰 발급 시 필요한 권한(repo, user, project 등)을 누락 없이 부여해야 정상 동작합니다.
  • 활용 팁: 각 서브 에이전트에 서로 다른 구별 색상(Purple, Orange 등)을 지정해두면 터미널상에서 현재 어떤 에이전트가 수행 중인지 한눈에 파악할 수 있습니다.

6. Antigravity + Supabase MCP 연동 방법

  • 핵심 요약 및 개요: 안티그래비티(AntiGravity)에 Supabase MCP를 연동하여 백엔드 서버 구축 없이 자연어 명령만으로 데이터베이스 및 사용자 인증 테이블을 연결하는 실습입니다.
  • 사용한 도구명: AntiGravity, Supabase, Supabase MCP Server.
  • 실습 절차:
    1. Supabase 웹사이트 회원가입 후 신규 조직 및 프로젝트를 생성하고, 계정 설정에서 Personal Access Token을 발급받습니다.
    2. AntiGravity 우측 상단 에이전트 메뉴의 MCP Servers -> MCP Store로 이동합니다.
    3. Supabase MCP를 검색하여 설치하고, 발급받은 Access Token을 입력하여 연동을 완료합니다.
    4. 채팅창에서 @index.html 등의 작업 코드를 참조하고, 데이터베이스 연동 및 테이블 작성을 요청합니다.
    5. AI 에이전트가 제시하는 RLS(Row Level Security) 보안 정책 및 테이블 생성 실행 계획을 승인하여 데이터베이스 구축을 마무리합니다.
  • 주의점: Access Token 발급 시 만료 기간을 'Never'로 설정하면 유출 위험이 있으므로 30일 등 제한된 기간으로 설정하는 것이 안전합니다.
  • 활용 팁: 복잡한 백엔드 설정 과정 없이도 MCP 연동을 통해 데이터 저장 및 회원가입/로그인 기능이 탑재된 완성형 웹사이트를 빠르게 빌드할 수 있습니다.

7. AntiGravity 2.0 , 본격적인 Agent 코딩의 시대

  • 핵심 요약 및 개요: 에이전트 중심 인터페이스로 전면 개편된 AntiGravity 2.0과 Gemini 3.5 Flash 모델을 활용하여 최소한의 프롬프트만으로 고품질 앱을 제작하는 방식을 소개합니다.
  • 사용한 도구명: AntiGravity 2.0, Gemini 3.5 Flash, GitHub, Netlify.
  • 실습 절차:
    1. AntiGravity 2.0을 설치 및 실행한 후 작업할 새 프로젝트 폴더를 지정합니다.
    2. 모델을 Gemini 3.5 Flash로 지정하고, 구현할 앱(예: 교육자용 투두리스트 앱) 핵심 요구사항을 한 줄의 자연어로 입력합니다.
    3. 에이전트가 스스로 세운 전체 실행 계획(Plan)을 확인하고 승인(Allow)하여 자동 생성을 진행합니다.
    4. 생성된 결과물 확인 후, GitHub 저장소 URL을 제공하여 해당 레포지토리에 코드를 자동 올리도록 지시합니다.
    5. Netlify에서 커밋된 저장소를 불러와 웹 배포를 완료합니다.
  • 주의점: 기존 코딩 툴 UI와 달리 에이전트 대화창이 메인을 차지하므로, 에이전트가 세운 작업 계획을 사전에 확인하는 습관이 필요합니다.
  • 활용 팁: Gemini 3.5 Flash 모델은 매우 짧은 프롬프트를 입력해도 집중 타이머, 소음기 등 세부 편의 기능을 스스로 판단하여 고도화된 완성본을 만들어냅니다.

8. Claude Code를 활용한 바이브 코딩 (무더위쉼터 찾는 사이트 만들기)

  • 핵심 요약 및 개요: 윈도우 환경에 클로드 코드를 설치하고, 이를 Cursor 에디터와 연동하여 공공데이터 포털 자료 기반의 실용적인 무더위쉼터 안내 웹사이트를 구축 및 배포합니다.
  • 사용한 도구명: Claude Code, Cursor, Node.js, 공공데이터포털 CSV/API, GitHub, Netlify.
  • 실습 절차:
    1. Node.js(18 버전 이상)를 설치한 후 명령 프롬프트에서 npm install -g @anthropic-ai/claude-code로 클로드 코드를 설치합니다.
    2. Cursor 에디터 실행 후 클로드 코드 익스텐션을 설치하고 터미널에서 claude를 불러옵니다.
    3. 공공데이터포털에서 다운로드받은 무더위쉼터 CSV 데이터 파일을 프로젝트 폴더에 위치시킵니다.
    4. 클로드 코드에게 기존 웹사이트 코드를 분석하여 UI를 고급스럽게 다듬고 기능을 고도화하도록 요청합니다.
    5. 수정이 완료된 파일(HTML, JS, CSS, CSV)을 GitHub에 커밋하고 Netlify를 통해 배포합니다.
  • 주의점: 윈도우 환경 설치 시 반드시 Node.js 18 버전 이상이 먼저 구동 환경으로 준비되어 있어야 클로드 코드가 정상 실행됩니다.
  • 활용 팁: Cursor 유료 구독 없이도 클로드 유료 사용자가 Cursor 터미널 내에서 Claude Code를 불러와 사용하면 익숙한 에디터 환경에서 효율적으로 작업할 수 있습니다.

  • 주의점: 아티팩트로 만들어진 공유 링크는 사용자가 Claude 계정의 토큰을 소비하여 동작하므로 작성자에게 API 비용이 발생하지는 않지만, 실제 독립형 상용 서비스로 배포하려면 코드를 추출해 별도 배포해야 합니다.
  • 활용 팁: 아이디어를 팀원들에게 말이나 텍스트로 설명하는 대신, 아티팩트로 3분 만에 동작하는 프로토타입을 만들어 링크로 공유하면 기획 의도를 시각적으로 명확하게 전달할 수 있습니다.

6. 클로드 코드도 배우고, 좋은 일도 할 수 있는 기회! :)

  • 핵심 요약 및 개요: Claude Code의 스킬(Skills) 및 서브 에이전트 기능을 활용해 반복적인 출제 및 교안 작성 업무를 자동화하고, 스터디 참여를 통해 사회적 기부를 실천하는 워크플로우입니다.
  • 사용한 도구명: Claude Code (Sub-Agents / Skills), NotebookLM, Cursor.
  • 실습 절차:
    1. NotebookLM에 행사나 교육 안내 텍스트를 넣어 슬라이드 덱 및 인포그래픽 요약 자료를 생성합니다.
    2. Cursor 터미널에서 Claude Code를 불러옵니다.
    3. Skill Creator 스킬을 사용해 문제 생성기(Quiz Generator) 및 수업 계획안 생성기(Lesson Plan Generator)라는 반복 업무용 커스텀 스킬을 구축합니다.
    4. 구축된 스킬을 불러와 "세계사 고대사 문제 템플릿을 만들어줘"와 같이 요청하여 시험지와 교안 초안을 자동 생성합니다.
    5. 봉사단 스터디 현장에 참여하여 에이전트 및 스킬 구동법, 배포 과정 교육을 이수하고 참가비를 통해 보육원 노트북 지원에 동참합니다.
  • 주의점: AI가 스킬을 통해 자동 생성해 준 시험 문제나 수업 계획안은 초안 개념이므로, 교육자가 반드시 내용을 검토하고 오류를 수정하여 사용해야 합니다.
  • 활용 팁: 매번 긴 프롬프트를 입력할 필요 없이, 자주 하는 반복 업무 프로세스를 스킬(Skills)로 등록해 두면 인수인계서를 건네듯 신속하게 정형화된 교안이나 문제를 생성할 수 있습니다.

7. 클로드 코드에 Supabase MCP 연동하기!

  • 핵심 요약 및 개요: Claude Code에 백엔드 서비스인 Supabase MCP를 연결하여, 터미널 환경에서 대화만으로 데이터베이스 테이블 스키마 생성 및 사용자 인증 로직을 구축하는 기법입니다.
  • 사용한 도구명: Claude Code, Supabase, Supabase MCP Server (.mcp.json).
  • 실습 절차:
    1. Supabase 사이트에서 계정을 만들고 Access Token을 발급받은 뒤, 신규 프로젝트를 만들어 Project Reference ID를 복사합니다.
    2. 구글에서 'Supabase MCP' 문서를 검색해 설치 명령어를 확인하거나, 작업 폴더 내 .mcp.json 파일에 Access Token과 Project Reference ID를 입력합니다.
    3. 터미널에서 Claude Code를 실행하고 /mcp 명령을 통해 Supabase MCP가 'Connected' 상태인지 확인합니다.
    4. 대화창에 "로그인 회원 시스템 및 사용자 데이터 저장을 위한 테이블을 Supabase에 구축해 줘"라고 지시합니다.
    5. Claude Code가 Supabase 서버에 직접 접속하여 데이터베이스 테이블 및 보안 규칙(RLS)을 자동 작성합니다.
  • 주의점: Supabase MCP 연동 상태에서 작업을 계속 진행하면 Claude 코딩 토큰 소모가 빠를 수 있으므로, 20달러 기본 요금제 사용자는 작업을 단계별로 분할하여 실행하는 것이 좋습니다.
  • 활용 팁: .mcp.json 설정 파일을 사용자 루트 폴더에 두면 모든 프로젝트에 동일한 Supabase가 적용되고, 개별 프로젝트 폴더에 두면 각 앱마다 별도의 전용 데이터베이스를 연동해 관리할 수 있습니다.

8. 클로드를 좋아하는 두 번째 이유 : 데스크탑 앱 + 클로드 코드

  • 핵심 요약 및 개요: 터미널 환경이 낯선 유료 사용자들을 위해, Claude 데스크톱 앱 내에 탑재된 Code 탭 인터페이스를 활용하여 손쉽게 웹앱 코딩부터 GitHub 푸시, Netlify 배포까지 완료하는 방법입니다.
  • 사용한 도구명: Claude Desktop App (Code 기능), Claude Projects (코딩 프롬프트 팀), GitHub, Netlify, Google AI Studio (Gemini API).
  • 실습 절차:
    1. Claude 데스크톱 앱을 설치하고 유료 계정(Pro 이상)으로 로그인합니다.
    2. Claude Projects를 통해 만들어진 상세 프롬프트(예: 사주 보는 웹앱)를 복사합니다.
    3. 데스크톱 앱 상단 메뉴에서 'Code'를 선택하고, 작업할 로컬 폴더 지정 및 GitHub 커넥터 연동을 완료합니다.
    4. 복사한 프롬프트를 코드 입력창에 넣고 에이전트가 코드를 구성하도록 승인합니다.
    5. 작업이 끝나면 내 GitHub 저장소 정보를 전달하여 코드를 자동 올리게 하고, Netlify와 연동해 배포합니다.
  • 주의점: 데스크톱 앱의 Code 기능은 20달러 유료 요금제(Pro 이상) 사용자만 접근 가능하며, 무료 사용자는 이용할 수 없습니다.
  • 활용 팁: 데스크톱 앱 내에서 코드를 추가 수정하면 연결된 GitHub 저장소로 자동 푸시되므로, 이미 배포된 Netlify 사이트 화면은 새로고침만 하면 최신 디자인이 즉시 반영됩니다.

9. 클로드를 좋아하는 여섯 번째 이유 : 클로드 코드 Claude Code

  • 핵심 요약 및 개요: 터미널 기반의 Claude Code 환경을 구축하고, 세부 역할별 서브 에이전트 및 GitHub MCP를 구성하여 자연어 명령만으로 웹사이트 제작부터 커밋, 배포까지 전 과정을 자동화하는 방법입니다.
  • 사용한 도구명: Claude Code, Node.js, Git, GitHub MCP, Sub-Agents, Netlify.
  • 실습 절차:
    1. Node.js와 Git을 설치한 후, 터미널에서 npm install -g @anthropic-ai/claude-code 명령어로 Claude Code를 설치합니다.
    2. 터미널에서 claude를 실행한 뒤, /agents 명령어로 역할별 에이전트(프론트엔드, 백엔드, 테스트, GitHub 담당 등)에 고유 색상과 툴 권한을 부여해 만듭니다.
    3. GitHub 토큰을 발급받아 GitHub MCP 연동을 완료합니다.
    4. 에이전트 팀에 원하는 웹사이트(예: 심리상담 웹앱) 제작 프롬프트를 입력하면 에이전트들이 순차적으로 개발 및 테스트를 진행합니다.
    5. GitHub 담당 에이전트가 레포지토리를 자동 생성해 코드를 올리면, Netlify에서 해당 저장소를 불러와 웹 배포를 마칩니다.
  • 주의점: 여러 에이전트가 자율적으로 협업하는 과정에서 생각보다 많은 토큰이 소모될 수 있으므로, 사용 한도를 미리 점검하면서 진행해야 합니다.
  • 활용 팁: 각 서브 에이전트마다 고유 색상(오렌지, 퍼플 등)과 제한된 툴 권한(Read-only, Edit 등)을 설정해두면 터미널상에서 에이전트별 작업 진행 상태를 시각적으로 명확하게 구분하고 관리할 수 있습니다.

10. 학부모님들을 위한 바이브 코딩 입문 수업을 합니다! :) (필로소피 AI 봉사단 3차 스터디 6월 28일 일요일)

  • 핵심 요약 및 개요: 코딩 경험이 없는 학부모나 교육자가 바이브 코딩(Vibe Coding) 기법을 배워, 자녀나 학생들을 위한 맞춤형 학습 보조 및 생활 관리 웹앱을 직접 만들어 보는 실습 안내입니다.
  • 사용한 도구명: Claude Code, Cursor, AntiGravity, Netlify.
  • 실습 절차:
    1. 자녀에게 필요한 맞춤형 앱 아이디어(예: 숙제 목록 체크, 엄마의 응원 쪽지함, 타이머 등이 포함된 습관 형성 앱)를 기획합니다.
    2. Claude Code 또는 Cursor, AntiGravity와 같은 AI 코딩 툴을 열고 원하는 앱의 구조와 디자인을 자연어로 지시합니다.
    3. AI가 생성해 준 코드를 테스트하고 추가하고 싶은 기능(칭찬 스티커, 오답 노트 등)을 대화로 수정합니다.
    4. 완성된 웹사이트 코드를 GitHub에 업로드하고 Netlify를 통해 무료 웹사이트 URL로 배포합니다.
    5. 생성된 주소를 자녀의 스마트폰이나 패드에 추가하여 실제 실생활 학습 관리에 활용합니다.
  • 주의점: 처음부터 너무 거대하고 복잡한 기능의 앱을 만들기보다는 자녀에게 당장 필요한 소규모 핵심 기능 하나부터 완성해 나가는 것이 바이브 코딩 성공률을 높입니다.
  • 활용 팁: 학부모가 직접 만든 앱을 자녀가 사용하는 경험을 통해 아이의 디지털 학습 흥미가 극대화되며, 스터디 참가비 기부를 통해 보육원 아동들에게 리퍼 노트북을 선물하는 사회적 가치도 실천할 수 있습니다.

11. 학생들도 쉽게 쓸 수 있는 바이브 코딩 Tool (Opal, Google AI Studio)

  • 핵심 요약 및 개요: 구글의 노코드 웹 빌더인 Opal과 Google AI Studio의 빌더 기능을 활용하여, 학생들이 코딩 한 줄 없이 프롬프트 입력만으로 시각적 퀴즈 및 멀티미디어 미니 앱을 쉽게 제작하는 수업 가이드입니다.
  • 사용한 도구명: Google Opal (opal.google), Google AI Studio (aistudio.google.com / Build Vibe CodeGen AI), Gemini 2.5 Flash / Pro.
  • 실습 절차:
    • Google Opal: opal.google 접속 -> 'Create New' 선택 -> "설악산 탐방 지리 안내 앱을 만들어줘" 입력 -> AI가 멀티미디어(텍스트, 이미지, 비디오) 생성 노드가 포함된 미니 앱 자동 구축 -> 'Share App' 퍼블릭 설정 후 카피 링크 공유.
    • Google AI Studio: aistudio.google.com 접속 -> 'Build Vibe CodeGen AI' 클릭 -> "세계사 연표 및 로마 제국 퀴즈 앱을 만들어줘" 입력 -> 오른쪽 미리보기 화면에서 직접 퀴즈를 풀며 수정 지시 -> 우측 상단 'Deploy' 버튼을 눌러 퍼블릭 웹사이트 배포.
  • 주의점: 구글의 두 도구 모두 자연어 한 줄로 완성되지만, 현재 실험적 단계의 무료 서비스이므로 일일 생성 및 호출 한도 제한이 적용될 수 있습니다.
  • 활용 팁: 선생님이 단순 강의를 진행하는 대신 학생들에게 직접 지리나 역사 주제에 대한 미니 앱을 만들고 서로의 링크를 공유해 공유 테스트를 해보게 하면 참여형 수업 효과를 극대화할 수 있습니다.
