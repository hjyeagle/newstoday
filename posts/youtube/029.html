시민개발자 구씨_n8n 자동화

선택하신 15개 영상에 대한 구체적인 요약본입니다. 요청하신 대로 각 영상 제목을 그대로 챕터명으로 지정하여 핵심 내용을 구체적인 항목으로 정리하였으며, 마지막에 '라벨 종합 정리'를 작성했습니다.

클로드 MCP로 안 되던 거, n8n으로 뚫었습니다! (커스텀 툴 구축 포함)

  • 기존 클로드 MCP 한계 극복: 수동 허용 권한 요청, 완전 자동화의 불가능성, 커스텀 툴 개발의 높은 코딩 장벽, 무료 플랜의 멀티 MCP 연결 리밋 등의 제약을 명확히 해결합니다.
  • 스케줄 트리거 기반 완전 자동화: 매일 정해진 시각에 수행되는 자동화 워크플로우(예: RSS 기반 매일 오전 10시 테크 뉴스 수집 및 슬랙 자동 발송)를 손쉽게 구축합니다.
  • n8n 단일 MCP 서버화: n8n 자체에 MCP 엑세스를 활성화하고 단 하나의 프로덕션 URL만 연결하여 n8n 내부의 수많은 툴과 워크플로우를 클로드 데스크톱에 통합 제공합니다.
  • 무료 플랜 사용자 툴 확장: 클로드 무료 사용자도 n8n MCP 서버 하나만 연결하면 구글 드라이브, 파이어크롤(웹 크롤링), 슬랙 뉴스 수집 등 다수의 커스텀 툴을 제약 없이 사용 가능합니다.
  • 콜 n8n 워크플로우 툴 활용: 구글 드라이브 내 PDF 파일 검색, 다운로드, 텍스트 추출, LLM 요약으로 이어지는 복잡한 커스텀 파이프라인을 구축해 호출합니다.
  • 노코드 커스텀 툴 자유도: 코딩 없이 사용자 입맛에 맞는 커스텀 MCP 툴을 자유롭게 확장하고 정밀 제어할 수 있는 유연성을 확보합니다.

나노바나나 무료 연결법 공개! n8n으로 이미지 편집부터 업로드까지 전부 자동화

  • 제미나이 2.5 플래시(나노바나나) 모델 연동: 뛰어난 이미지 생성/편집 퀄리티와 빠른 속도를 자랑하는 구글의 나노바나나 모델을 n8n과 연결합니다.
  • 오픈라우터(OpenRouter) 무료 API 활용: 구글 AI 스튜디오 API의 유료 전환 제약을 극복하기 위해 오픈라우터의 무료 프리뷰 모델 API 키를 발급받아 n8n에 연결합니다.
  • n8n 폼(Form) 기반 레퍼런스 수집: 폼 트리거를 통해 레퍼런스 이미지, 오리지널 소스 이미지, 편집 요청 프롬프트를 한 번에 수집·입력받습니다.
  • 베이스64 스트링 변환 및 제이슨 가공: 수집된 이미지를 베이스64(Base64) 스트링으로 추출·변환한 뒤, 이미지 유무 형태에 맞춰 코드 노드로 제이슨 파라미터를 가공합니다.
  • 챗GPT 프롬프트 고도화 및 구글 드라이브 저장: 챗GPT(GPT-4o)로 이미지 프롬프트를 영문으로 고도화하고, 나노바나나 모델을 호출해 편집된 최종 이미지를 구글 드라이브 폴더에 자동 업로드합니다.
  • 실무 디자인 파이프라인 자동화: 배경 스타일 변경, 인물 포즈 합성, 텍스트 기반 로고 생성 등 실무용 디자인 작업을 노코드로 구현합니다.

n8n MCP 이렇게 쉬워졌습니다 – 코딩 없이 MCP 서버 만들기

  • 인스턴스 레벨 MCP 업데이트: 워크플로우마다 MCP 노드를 개별 배치할 필요 없이, 설정에서 MCP 엑세스를 활성화하고 단일 서버 URL을 발급받는 방식으로 설정이 간소화됩니다.
  • AI 어시스턴트 단일 URL 연동: 클로드 데스크톱 공식 커넥터나 챗GPT 개발자 모드 커넥터에 n8n 단일 서버 URL 및 베어 토큰만 등록하여 전체 n8n 워크플로우를 연결합니다.
  • 'Available in MCP' 옵션 제어: 각각의 워크플로우 세팅에서 'Available in MCP' 옵션을 체크하기만 하면 AI가 해당 워크플로우를 스스로 검색하고 실행할 수 있습니다.
  • CRM 시트 업데이트 툴 구축: **폼 트리거(Form Trigger)**를 활용해 컴패니명, 담당자, 이메일, 요청사항 필드를 구성하여 메일 문의 내용을 CRM 구글 시트에 행 추가(Append Row)하는 툴을 구축합니다.
  • 자연어 명령 기반 원스톱 실행: 챗GPT/클로드에서 단 한 줄의 자연어 요청만으로 지메일 초안 작성, 견적서 PDF 생성 및 메일 발송까지 유기적으로 가동합니다.
  • 무제한 가성비 및 유연성: 제피어 MCP 대비 비용 제한이 없고, 사용자가 원하는 워크플로우 실행 로직을 세밀하게 노코드로 자유롭게 설계할 수 있습니다.

n8n 워크플로우, 이제 직접 안 만듭니다 (Claude Code 초보자 가이드)

  • 클로드 코드 바이브 코딩 환경 구축: 클로드 코드를 설치하고 VS 코드 터미널 환경에서 바이패스 권한 및 n8n 연동 환경을 구성합니다.
  • n8n 전용 AI 개발 전문가 구현: n8n CLI/API와 스킬스(Skills)를 클로드 코드에 장착시켜, n8n 노드 작성과 JSON 구조 생성을 전문적으로 수행하도록 설정합니다.
  • SOP 및 CLAUDE.md 가이드 문서 구성: 목표 시스템의 구조와 트리거, 로직, 에러 처리, 로깅 방식을 정리한 표준 업무 매뉴얼(SOP.md) 및 CLAUDE.md 가이드 문서를 작성하여 AI의 오작동을 방지합니다.
  • 완성형 JSON 워크플로우 자동 빌드: 클로드 코드가 n8n API를 호출하여 세부 노드 연결 및 파라미터 세팅이 포함된 완성형 JSON 워크플로우를 자동 생성합니다.
  • 시각적 피드백 및 정밀 보완: 노드 맵핑 오류나 기능 누락 발생 시, 캔버스 화면을 스크린샷으로 캡처해 클로드 코드에 피드백하면 이를 정밀 보완·재생성합니다.
  • 빌드 속도와 유지보수성의 결합: 클로드 코드의 빠른 노드 빌드 능력과 n8n의 시각적 워크플로우 관리·유지보수 강점을 결합하여 고도화된 자동화 시스템을 완성합니다.

ChatGPT, Claude, Gemini를 n8n으로 통합하면?

  • n8n 챗 허브(Chat Hub) 출시: 챗GPT, 클로드, 제미나이 등 각 AI 모델별로 파편화된 대화 맥락, 구독료 누적, MCP 설정의 제약을 한 번에 해결하는 챗 어시스턴트 기능입니다.
  • 단일 세션 내 멀티 모델 크로스 활용: 단일 대화 세션 내에서 퍼플렉시티 소나(리서치) -> 클로드 오퍼스(분석 및 선별) -> 제미나이 프로(문서 재구성)로 모델을 스위칭하면서도 맥락(Context)을 완벽히 유지합니다.
  • 비용 통제 및 무료 모델 결합: 오픈라우터(OpenRouter) API 키를 연동해 사용한 만큼만 과금하거나 무료 오픈소스 모델을 결합하여 무분별한 구독 비용을 통제합니다.
  • 맞춤형 퍼스널 에이전트 구축: 시스템 프롬프트와 구글 서치 API 툴을 결합한 **퍼스널 에이전트(Personal Agent)**를 생성해 주간 AI 트렌드 브리핑 전용 챗봇을 맞춤 제작합니다.
  • 워크플로우 에이전트 내장: n8n의 챗 트리거(Chat Trigger) 노드를 활용해 AI 뉴스 수집 및 구글 시트 자동 기록 기능을 가진 워크플로우 에이전트를 챗 허브에 내장해 가동합니다.
  • 자동 멀티모델 오케스트레이션: 질문 의도(리서치 vs 문서 요약 vs 정의 질문)에 따라 모델 셀렉터 노드가 자동으로 퍼플렉시티, 클로드, 오픈소스 무료 모델로 분기·처리하도록 구축합니다.

1분 만에 실무용 이미지·영상 제작 완성! n8n + 챗GPT + Runway 자동화 튜토리얼

  • 이커머스 상세페이지 콘텐츠 자동화: 제품 사진과 설명만 입력하면 1~2분 만에 스튜디오급 이미지와 영상을 자동 생성하는 n8n 폼(Form) 기반 시스템을 구축합니다.
  • 코드 노드를 통한 아이템 스플릿: 입력받은 제품 이미지와 설명, 앵글 옵션(정면/뒷면)을 코드 노드로 스플릿 아이템 처리하여 개별 프로세스로 분리합니다.
  • 챗GPT 프롬프트 고도화 및 이미지 API 연동: 챗GPT(GPT-4o) 베이스 LM 체인으로 한국어 설명을 영문 프로덕트 포토 프롬프트로 고도화하고, HTTP 리퀘스트 노드로 챗GPT 최신 이미지 생성 API를 직접 연동합니다.
  • 런웨이(Runway Gen-4 Turbo) 영상 생성: 생성된 정면 이미지를 IMGBB 서비스로 공개 웹 URL로 변환한 뒤, 런웨이 API에 주입하여 10초 분량의 턴테이블 회전 비디오를 생성합니다.
  • 웨이트 및 루프 체크 상태 감지: 웨이트(Wait) 노드와 루프 체크 노드를 구성해 영상 생성 완료 상태(Succeeded)를 주기적으로 감지하고 MP4 비디오 파일 및 이미지 파일들을 수집합니다.
  • 에어테이블(Airtable) 아카이빙: 메타데이터 및 완성된 파일 URL을 에어테이블 데이터베이스에 자동 아카이빙하여 한눈에 관리하는 시스템을 완결합니다.

카카오톡 비즈채널 자동화 끝판왕! n8n + Solapi로 친구톡·알림톡 발송

  • 카카오톡 비즈니스 채널 세팅: 카카오 비즈니스 채널 개설, 프로필/검색 허용 설정, 고객센터 번호 등록 및 비즈니스 채널 승인 절차를 체계적으로 진행합니다.
  • 솔라피(Solapi) API 연동: 카카오 비즈니스 메시지 대행 서비스인 솔라피의 API 키와 시크릿을 발급받아 n8n과 연동합니다.
  • HMAC-SHA256 암호화 인증 구현: n8n 내 크립토(Crypto) 노드를 사용해 Date 타임, Random 솔트, API 시크릿을 결합한 HMAC-SHA256 시그니처 해시 암호화 인증 헤더를 생성합니다.
  • 친구톡 모듈 구축: 기존 채널 친구들에게 텍스트, 광고 플래그, 버튼 링크가 포함된 마케팅 메시지를 자동 전송합니다.
  • 알림톡 모듈 구축: 사전 검수 및 승인된 템플릿 ID와 고객 변수(이름 등)를 매핑해 채널 미추가 고객에게도 중요한 안내/가입 메시지를 전달합니다.
  • 루프 기반 배치 대량 발송: 구글 시트에서 수신 동의(Y) 고객 명단을 획득한 뒤, 루프 오버 아이템스(Loop Over Items) 노드로 200개씩 배치 제이슨 코드를 생성하여 대량 메시지를 안전하게 자동 발송합니다.

코딩없이 가능한 AI 에이전트! 초보자용 n8n 실전 튜토리얼

  • AI 체인 vs AI 에이전트 차이: 정해진 순서대로 작동하는 AI 체인(Chain)과 달리, AI 에이전트는 목표 달성을 위해 스스로 상황을 판단하고 알맞은 툴을 선택해 작업을 실행함을 설명합니다.
  • 개인 비서 에이전트 구조: 챗 메시지 트리거에 OpenAI GPT-4o-mini 두뇌, 대화 이력을 기억하는 심플 메모리(Simple Memory), 그리고 외부 액션 툴들을 결합하여 개인 비서 시스템을 구축합니다.
  • 구글 핵심 서비스 툴 연동: 구글 캘린더 툴(일정 조회, 추가, 삭제)과 구글 시트 툴(연락처/팀원 정보 조회), 지메일 툴(리마인더 메일 발송)을 에이전트에 손발로 연결합니다.
  • GCP OAuth 2.0 권한 설정: 구글 클라우드 콘솔(GCP)에서 OAuth 2.0 클라이언트 ID 및 리다이렉트 URI, 앱 범위(Scope)를 설정하여 n8n 셀프호스팅 환경에 구글 권한을 연결합니다.
  • 자연어 기반 복합 업무 수행: "내일 일정 브리핑해 줘", "저녁 7시 미팅 추가하고 샌더에게 리마인더 메일 보내줘"라는 자연어 명령을 에이전트가 판단해 캘린더 등록 및 지메일 발송을 완결합니다.
  • 독립형 호스티드 챗 배포: 호스티드 챗(Hosted Chat) 전용 URL을 활성화해 자비스 형태의 나만의 독립형 AI 챗봇 웹 페이지로 배포·활용합니다.

문서만 넣으면 AI가 대신 답한다?! 15분만에 n8n으로 RAG Agent 만들기

  • RAG(검색 증강 생성) 작동 원리: 대용량 문서에서 질문 관련 정보만 검색(Retrieval)하여 정확히 생성(Generation)하는 RAG 시스템의 작동 원리를 설명합니다.
  • 슈퍼베이스(Supabase) 벡터 DB 연동: 무료 오픈소스 데이터베이스인 슈퍼베이스를 결합하여 임베딩 벡터와 관계형 테이블을 동시에 운용합니다.
  • 자동 파이프라인 및 청킹 처리: 구글 드라이브 폴더 감지 트리거로 PDF/구글독스 문서를 다운로드하고, 리커시브 텍스트 스플리터로 청킹 후 임베딩(Text Embedding 3 Small) 처리하여 벡터 스토어에 적재합니다.
  • RAG 에이전트 가드레일 설정: AI 에이전트에 슈퍼베이스 벡터 스토어 리트리버 툴과 GPT-4o-mini 모델을 결합하고 "문서 내용에 기반해서만 한글로 답할 것"이라는 가드레일 프롬프트를 부여합니다.
  • 정확한 정보 발췌 및 환각 방지: "겸업 관련 조항", "6개월 미만 재직자 연차 사용", "배송 지연 환불 CS 조치" 등 구체적 질의 시 정확한 청크를 발췌하여 환각 없이 완벽하게 답변합니다.
  • 전사 공유 및 웹 배포: 대화 내역 저장을 위한 메시지 인 메모리와 퍼블릭 챗 URL 배포를 통해 전사 사원용 자동 응대 RAG 에이전트를 15분 만에 완성합니다.

n8n에 클로드 스킬 붙였더니 일반 AI 노드랑 결과가 완전 달라졌습니다!

  • 클로드 스킬스(Skills) API 연동: 업무 SOP 매뉴얼, 참고 자료, 파이썬 코드 스크립트를 패키징한 클로드 스킬스를 클로드 콘솔(Console) API에 업로드하여 n8n과 연동합니다.
  • 단일 HTTP 리퀘스트 노드로 완결: n8n 내 HTTP 리퀘스트 노드로 클로드 스킬 API(소넷 3.5 / 하이쿠)를 호출해 유튜브 데이터를 전달하고, 파생 지표 계산과 차트 생성이 결합된 워드(DOCX) 리포트를 단 하나의 노드로 생성합니다.
  • 노드 파이프라인의 압도적 단순화: 기존 일반 LLM 노드 방식은 템플릿 생성, 100여 개 자리 표시자 맵핑, 퀵차트 API 연결 등 20여 개의 노드가 필요했던 반면, 스킬 API는 7개 노드로 대폭 단순화합니다.
  • 정확한 파이썬 스크립트 수치 계산: 파이썬 코드 스크립트 실행을 포함하는 스킬 특성 덕분에 참여도, 연간 총 조회수, 구독 전환율 등 파생 지표 수치 계산 오차 없이 완벽하게 반영합니다.
  • 안정적 타임아웃 세팅 및 구글 드라이브 업로드: 타임아웃 시간을 3,600초로 여유 있게 세팅하여 대용량 리포트 생성을 완료하고, 추출된 파일 ID로 완성된 워드 보고서를 구글 드라이브에 자동 업로드합니다.
  • 독보적 생산성 효율 입증: 복잡한 문서 양식이나 유효성 검증, 데이터 계산이 결합된 작업을 AI 노드 수십 개 대신 단 하나의 클로드 스킬 API 노드로 대체합니다.

  • 오픈AI 에이전트 빌더(Agent Builder) 분석: 오픈AI가 플랫폼 대시보드에 출시한 비주얼 캔버스 형태의 에이전트 빌더 구성 요소와 특성을 분석합니다.
  • 특화 노드 구성: 제일브레이크/환각 방지용 가드레일(Guardrails) 노드, 질문 의도 분류(Classification) 노드, 조건문(If/Else), 유저 승인(User Approval) 노드를 직관적으로 배치해 체봇 워크플로우를 구성합니다.
  • 멀티 에이전트 핸드오프(Handoff): 고객 환불, 구독 해지, 일반 문의로 질문을 분류한 뒤 각 상황별 전문 에이전트로 전달하여 적절한 할인 혜택이나 해지 절차를 안내합니다.
  • 그레이더(Grader) 기반 정량 평가: 테스트 후 그레이더 평가 기능을 가동해 유창성, 간결성, 정책 준수 여부를 LLM 저지로 평가하고 프롬프트 최적화를 진행합니다.
  • 체킷(ChatKit) 위젯 및 UI 커스텀: 완성된 에이전트는 체킷 위젯 및 코드 연동을 통해 웹사이트에 스타일리시한 UI 체봇 형태로 즉시 임베딩합니다.
  • n8n과의 차별점 및 적용 영역: n8n은 스케줄/웹훅 기반의 완전 자동화 및 복잡한 API 연동에 우월한 반면, 오픈AI 에이전트 빌더는 웹사이트 고객 응대 체봇 제작 및 체킷 UI 커스텀에 특화되어 있음을 정립합니다.

  • 이밸루에이션(Evaluation) 정량 평가: AI 에이전트의 퀄리티와 프롬프트, 모델, 청크 사이즈의 적합성을 n8n 이밸루에이션 기능을 통해 정량적 숫자로 평가하고 개선합니다.
  • 테스트 데이터셋 구축: n8n 내 데이터 테이블(Data Table)에 질문, 본문, 정답지(Expected Category / Priority / Answer)가 담긴 테스트 데이터셋을 사전 구축합니다.
  • 카테고리 및 우선순위 검증: 패칭 데이터셋 트리거와 셋 매트릭스(Set Metrics) 노드를 구성해 카테고리 정확도(Is Equal) 및 우선순위 일치 여부를 자동 산출합니다.

  • LLM 저지(LLM Judge) 척도 평가: RAG 에이전트 평가 시 LLM 저지 지표 노드를 붙여 1~5점 척도로 답변 정확성과 참조 청크 관련성을 자동 평가합니다.
  • Check if Evaluating 노드 분기: Check if Evaluating 노드를 활용해 실제 운영 데이터는 데이터 테이블에 자동 누적하고, 평가 실행 시에는 이밸루에이션 루프로 분기시켜 시스템을 지속적으로 업그레이드합니다.

n8n AI 자동화, 사람이 빠지면 진짜 사고 납니다 (실무 자동화의 핵심은 이것!)

  • 휴먼인더루프(Human-in-the-loop)의 중요성: AI 결과물의 환각이나 오류로 인한 사고를 방지하고 실무 안정성을 확보하기 위해 자동화 루프에 사람이 직접 개입하는 구조를 구축합니다.
  • 승인/거절 버튼 형태 연동: 재무 분석 에이전트 실행 후 텔레그램으로 분석 결과와 함께 '시트 업로드' 및 '드롭' 버튼을 전송하고, 사람이 승인 버튼을 누른 경우에만 구글 시트에 아카이빙합니다.
  • 텍스트 피드백 수집 및 연동: 리서치 에이전트 실행 후 텔레그램 폼으로 정성적 피드백 텍스트를 수집합니다.
  • 텍스트 클래시파이어(Text Classifier) 자동 분류: 텍스트 클래시파이어 노드를 활용해 사용자 피드백을 '승인'과 '재작성' 카테고리로 자동 분류합니다.
  • 승인 시 슬랙 포매팅 자동 공유: 승인 판정 시 슬랙 포매터 노드가 메시지를 블록킷(Block Kit) 포맷으로 변환해 슬랙 채널에 공유합니다.
  • 무한 피드백 수정 루프 구현: 재작성 판정 시 피드백 내용과 기존 요약본을 들고 2차 리서치 에이전트로 넘어가 내용을 재가공한 뒤, 다시 텔레그램 피드백 루프로 돌아가는 무한 피드백 수정 루프를 완성합니다.

라벨 종합 정리

  • n8n은 코딩 없이 AI 모델(ChatGPT, Claude, Gemini, 나노바나나)과 외부 앱(구글 워크스페이스, 슬랙, 카카오톡, 런웨이, 슈퍼베이스 등)을 자유롭게 결합하여 고도화된 업무 자동화 및 RAG/에이전트 시스템을 구축하는 핵심 플랫폼입니다.
  • AI 워크플로우 빌더, 클로드 코드, MCP 및 스킬스 연동을 통해 시스템 기본 뼈대를 수분 만에 신속하게 빌드하고, 챗 허브 및 다양한 AI 모델 오케스트레이션으로 생산성과 가성비를 대폭 끌어올릴 수 있습니다.
  • 완벽한 자동화에만 의존하지 않고 휴먼인더루프(Human-in-the-loop) 승인 절차와 n8n 이밸루에이션(Evaluation) 기반의 정량적 점수 검증을 결합함으로써 사고 없는 고품질 비즈니스 자동화를 완성합니다.
