1. (Gemma4) 무료로 로컬에서 사용 가능한 구글 딥마인드의 오픈소스 모델

  • 핵심 요약 및 개요: 구글 딥마인드가 공개한 멀티모달 오픈소스 AI 모델인 Gemma 4의 특징과 설치법을 배우고, Ollama 및 AntiGravity를 통해 인터넷 연결 없이 로컬 환경에서 구동되는 스트림릿(Streamlit) 웹앱을 구축하는 실습입니다.
  • 사용한 도구명: Google Gemma 4 (E2B / E4B / 26B 등), Ollama, AntiGravity, Streamlit, Python.
  • 실습 절차:
    1. Ollama 공식 사이트에 접속하여 Ollama 프로그램을 다운로드 및 설치합니다.
    2. 시작 메뉴에서 CMD 명령 프롬프트를 열고 ollama run gemma4:e4b 명령어를 입력하여 Gemma 4 모델을 다운로드 및 구동합니다.
    3. AntiGravity에서 새 작업 폴더를 열고 Gemini 3.1 Pro / Flash 모델을 선택한 후 대화창을 엽니다.
    4. Ollama와 Gemma 4 E4B 모델을 연동하여 작동하는 교육용 스트림릿 웹사이트 제작 프롬프트를 입력해 파이썬 코드를 생성합니다.
    5. requirements.txt 패키지 설치 후 streamlit run app.py 명령어로 웹 앱을 실행하여 로컬 브라우저에서 이미지(수학 문제, 영어 수능 문제 등) 분석 및 교안 작성 기능을 테스트합니다.
  • 주의점: 사용자 PC의 하드웨어 사양(RAM 및 VRAM)에 맞는 적절한 모델 크기(E2B, E4B, 26B 등)를 선택해야 속도 지연이나 다운 현상 없이 안정적으로 작동합니다.
  • 활용 팁: 인터넷 연결 없이 완벽한 오프라인 환경에서 작동하므로 API 비용이나 월 구독료 부담이 없으며, 학생 개인정보나 시험 문제 유출 걱정 없는 보안 채봇으로 활용할 수 있습니다.

2. (실습) AI가 암세포 치유에 도움을 주는 시대 (Cell to Sentence Scale Gemma 2 2b)

  • 핵심 요약 및 개요: 유전자 발현 데이터를 문장(Sentence) 형태로 변환하는 Cell to Sentence (C2S) 기술과 Gemma 2 모델을 결합하여, 세포 타입을 자동 예측하고 신약 개발 가설을 세우는 생물정보학 AI 실습입니다.
  • 사용한 도구명: C2S Scale Gemma 2 (2B / 27B), Google Colab, Hugging Face (han-daker-lab), Python.
  • 실습 절차:
    1. 제공된 구글 코랩(Google Colab) 링크로 접속하여 드라이브 사본 저장을 진행합니다.
    2. 첫 번째 셀을 실행하여 C2S 분석에 필요한 라이브러리를 설치합니다.
    3. 유전자 정보(CD3D, CD5E 등 발현량순 나열)가 담긴 세포 문장 형태의 샘플 데이터를 생성합니다.
    4. Hugging Face에서 C2S Scale Gemma 2 2B 모델 및 최적화된 프롬프트를 로드합니다.
    5. 예측 함수를 실행하여 샘플 데이터의 세포 타입(T-세포, B-세포 등)을 분류하고 정확도(62.5% 등) 및 시각화 그래프 결과를 확인합니다.
  • 주의점: 코랩 무료 GPU 환경 제약으로 소형 2B 모델을 주로 실습에 사용하지만, 실제 연구 수준의 정밀한 예측 능력을 확보하려면 27B 모델을 사용하는 것이 권장되며, AI의 제안은 임상실험을 통한 검증이 필수적입니다.
  • 활용 팁: 면역세포가 암세포를 찾기 어려운 차가운 종양(Cold Tumor)을 치료가 쉬운 뜨거운 종양(Hot Tumor)으로 변환할 약물을 AI 패턴 탐색으로 빠르게 스크리닝할 수 있습니다.

3. [내 PC에서 로컬 파인튜닝] Unsloth Docker 설치법

  • 핵심 요약 및 개요: 구글 코랩의 사용 시간 및 자원 한계를 극복하기 위해, 내 PC에 Docker와 WSL2 환경을 구축하여 Unsloth 기반의 독립적인 로컬 파인튜닝 환경을 세팅하는 방법입니다.
  • 사용한 도구명: Unsloth, Docker Desktop, WSL2 (Linux용 Windows 서브시스템), NVIDIA GPU Drivers, PowerShell, Jupyter Notebook (localhost:8888).
  • 실습 절차:
    1. PowerShell을 관리자 권한으로 열고 wsl --install 명령어로 WSL2를 설치한 뒤 재부팅합니다.
    2. 도커 데스크탑(Docker Desktop)을 설치하고, 설정에서 'Use the WSL 2 based engine' 및 Ubuntu 연동을 활성화합니다.
    3. 관리자 파워셸에서 지정 폴더로 이동한 후, 언슬로스 도커 실행 명령어와 함께 로그인 접속 비밀번호를 설정하여 실행합니다.
    4. 7GB 분량의 도커 컨테이너 이미지 다운로드가 완료될 때까지 5~10분간 대기합니다.
    5. 웹 브라우저 주소창에 localhost:8888을 입력하고 설정한 비밀번호를 입력해 주피터 노트북 내 언슬로스 파인튜닝 템플릿에 접속합니다.
  • 주의점: NVIDIA GPU(VRAM 8GB 이상)가 탑재된 윈도우/리눅스 PC 환경이 필수적이며, Mac 사용자는 NVIDIA GPU 부재로 도커 설치 대신 구글 코랩이나 클라우드 GPU 사용이 권장됩니다.
  • 활용 팁: 도커 컨테이너 방식으로 설치하면 라이브러리 간 버전 충돌 및 환경 재설정 번거로움 없이 안전하고 동일한 파인튜닝 작업 공간을 언제든 오프라인으로 이용할 수 있습니다.

4. [올라마 클라우드] 선생님들 이제 큰 사이즈의 오픈소스 AI도 써볼 수 있습니다!

  • 핵심 요약 및 개요: 고성능 그래픽 카드가 없는 개인 컴퓨터에서도 올라마 클라우드(Ollama Cloud) 인프라를 연결하여 600B급 이상의 초대형 오픈소스 AI 모델을 빠르게 구동하고 테스트하는 가이드입니다.
  • 사용한 도구명: Ollama Cloud, Terminal / CMD, DeepSeek V3.1 (671B), GPT-OSS (120B), Qwen 3 Coder (480B).
  • 실습 절차:
    1. Ollama 웹사이트에 접속하여 회원가입 및 구글 계정 로그인을 마칩니다.
    2. 터미널 또는 CMD 창을 열고 ollama signin 명령어를 입력해 클라우드 계정을 인증합니다.
    3. 대형 클라우드 전용 모델 명령어(예: ollama run deepseek-v3.1:671b-cloud)를 입력합니다.
    4. 클라우드 서버 세션이 연결되면 터미널상에서 대형 AI 모델 로딩 완료를 확인합니다.
    5. 양자역학 개념 설명, AI 에이전트 동작 원리, 테트리스 게임 코드 작성 등을 입력하여 압도적인 응답 속도와 완성도를 확인합니다.
  • 주의점: 현재 프리뷰 단계로 무료 이용이 가능하지만 시간당/일일 사용량 제한이 존재하며, 추후 유료 과금 요금제로 전환될 수 있으므로 한도를 확인하며 사용해야 합니다.
  • 활용 팁: 개인 노트북 사양의 한계로 다운로드조차 불가능했던 초대형 오픈소스 AI 모델들을 PC 배터리 소모나 발열 없이 클라우드 파워를 빌려 즉시 수업 준비나 코딩 연구에 활용할 수 있습니다.

5. [임베딩 젬마] 100개 언어 지원하는 구글의 새로운 임베딩 모델

  • 핵심 요약 및 개요: 구글의 초경량 다구어 임베딩 모델인 Embedding Gemma와 Qwen 3 (4B) 추론 모델을 연동하여, PDF 문서를 100개 이상의 언어로 빠르게 벡터화하고 고성능 로컬 RAG 검색 시스템을 구축하는 기법입니다.
  • 사용한 도구명: Google Embedding Gemma (308M), Qwen 3 (4B), Ollama, Python, Streamlit, Cursor / Code Editor.
  • 실습 절차:
    1. CMD/터미널에서 ollama pull embedding-gemma 및 ollama run qwen3:4b 명령어로 두 모델을 설치합니다.
    2. 파이썬 코드(app.py)와 requirements.txt 패키지 파일을 준비하고 터미널에서 라이브러리를 설치합니다.
    3. streamlit run app.py 명령어로 로컬 브라우저에서 RAG 전용 분석 웹사이트를 구동합니다.
    4. PDF 문서(예: 미국 CPI 관련 증권사 분석 보고서)를 업로드하여 텍스트 추출 및 청크(Chunk) 단위 분할을 진행합니다.
    5. Embedding Gemma가 문서를 숫자 벡터로 전환한 뒤 질문을 입력하면, 코사인 유사도가 높은 청크를 찾아 Qwen 3 추론 모델이 깔끔한 한글 요약 답변을 도출하도록 합니다.
  • 주의점: RAG 시스템 구축 시 텍스트를 벡터로 변환하는 임베딩 모델(Embedding Gemma)과 검색된 결과를 종합해 답을 쓰는 LLM 추론 모델(Qwen 3 등) 두 가지가 모두 준비되어 있어야 정상 작동합니다.
  • 활용 팁: 200MB 미만의 매우 적은 RAM 메모리만으로 구동 가능하므로, 논문이나 보고서를 많이 읽는 연구자 및 교사가 인터넷이 끊긴 상태에서도 민감한 문서를 최고 수준의 보안으로 빠르게 임베딩 및 요약 분석할 수 있습니다.

6. Fine Tuning 실습 (AI로 만든 합성 데이터로 AI 학습시키기)

  • 핵심 요약 및 개요: 연구 논문 PDF 파일만 제공하면 Meta Synthetic Data Kit가 Q&A 학습 데이터를 자동으로 추출해 합성 데이터(Synthetic Data)를 구성하고, 이를 Unsloth로 Llama 3.2 3B 모델에 파인튜닝시키는 자동화 워크플로우입니다.
  • 사용한 도구명: Unsloth, Meta Synthetic Data Kit, Llama 3.2 3B, Google Colab (GPU / T4 or A100), Hugging Face, Ollama / LM Studio.
  • 실습 절차:
    1. 제공된 구글 코랩 사본을 저장하고 GPU 런타임(T4 또는 A100)을 설정합니다.
    2. Unsloth 및 Meta Synthetic Data Kit 패키지를 설치합니다.
    3. 원본 논문 PDF 주소를 불러와 청크로 분할한 후 Synthetic Data Kit를 실행해 질문과 답변(Q&A) 쌍의 합성 데이터셋을 자동 생성합니다.
    4. 정제된 데이터를 제이슨(JSON) 형식으로 변환하여 Llama 3.2 3B 모델과 LoRA 어댑터 환경에 로드합니다.
    5. SFTTrainer로 파인튜닝을 진행한 후, 학습된 모델을 GGUF 포맷으로 변환하여 본인의 Hugging Face 레포지토리에 자동 올립니다.
  • 주의점: Hugging Face 저장소 업로드 시 반드시 쓰기(Write) 권한이 있는 Access Token을 입력해야 하며, 훈련 단계 설정값(Epochs)을 적절히 조절해야 오버피팅을 예방할 수 있습니다.
  • 활용 팁: 사람이 일일이 수백~수천 개의 Q&A 수작업 데이터를 만들 필요 없이 전문 학술 논문 하나만 넣어주면 합성 데이터 구성부터 파인튜닝 모델 추출까지 일괄 자동 처리할 수 있습니다.

7. Gemma 4, 나만의 로컬 법무팀

  • 핵심 요약 및 개요: 내 PC에 Gemma 4 (26B) 모델을 설치하고 에이전트 지침 및 경찰청 양식을 부여하여, 외부 클라우드 유출 없이 안전하게 고소장이나 계약서 초안을 작성해 주는 오프라인 법무 전용 시스템을 구축합니다.
  • 사용한 도구명: Google Gemma 4 (E4B / 26B), Ollama, AntiGravity, Streamlit, Python.
  • 실습 절차:
    1. Ollama 설치 후 CMD 창에서 ollama run gemma4:26b 명령어로 모델을 다운로드 및 구동합니다.
    2. Ollama 앱 인터페이스에서 법무 전용 에이전트 워크플로우 지침(프롬프트)을 입력합니다.
    3. 경찰청 민원 포털의 표준 고소장 양식 템플릿과 중고거래 피해 등의 사실관계 데이터를 제공합니다.
    4. Gemma 4 모델이 양식 규격에 맞춰 사건 경위, 고소 취지, 관련 날짜가 정리된 고소장 초고를 자동 생성하도록 합니다.
    5. AntiGravity로 생성한 스트림릿 웹사이트를 통해 사실관계를 입력하고 수정된 결과를 워드 문서(.docx) 파일로 다운로드합니다.
  • 주의점: AI는 정식 법률 전문가가 아니므로 존재하지 않는 법조항이나 판례를 만들어내는 환각(Hallucination) 현상이 발생할 수 있습니다. 반드시 생성된 내용을 사람이 검증하고 초안 작성 목적으로만 활용해야 합니다.
  • 활용 팁: 민감한 기밀 서류나 개인 사생활 관련 법률 문서를 외부 AI 서버로 전송하지 않고 내 컴퓨터 안에서 완벽한 프라이버시 보호 하에 24시간 무료로 검토하고 서식을 작성할 수 있습니다.

8. Gemma 4, 나만의 로컬 재무팀

  • 핵심 요약 및 개요: Gemma 4 (26B) 모델에 알렉스·미아·크리스 등으로 구성된 재무 분석 에이전트 워크플로우를 탑재하고, 엑셀 재무제표 원본 데이터를 입력받아 자동 손익 분석 및 보고서를 생성하는 실습입니다.
  • 사용한 도구명: Google Gemma 4 (E4B / 26B), Ollama, AntiGravity, Streamlit, Python (Pandas / openpyxl).
  • 실습 절차:
    1. Ollama 사이트에서 Gemma 4 모델을 다운로드합니다.
    2. AntiGravity에서 고정 댓글의 GitHub 레포지토리 주소를 참조시켜 엑셀 업로드용 재무 분석 스트림릿 웹앱 코드를 생성합니다.
    3. streamlit run app.py 명령어로 재무 전용 로컬 웹 사이트를 실행합니다.

  • 주의점: 지식 증류 시 템퍼러처(\\(T\\)) 값을 적절히 높여야 오답 선택지들 간의 유의미한 확률 정보(다크 날리지)가 소실되지 않고 스튜던트에게 전달됩니다.

11. 파인튜닝 GRPO 실습 (AI가 제시하는 여러 답변에 보상을 제공하며 학습시키기)

  • 핵심 요약 및 개요: 기존의 절대점수 방식(PPO)과 달리, AI가 4~8개의 답변을 동시 생성하도록 한 뒤 그룹 내 상대적 우위 순위에 보상(Reward)을 부여해 추론 능력을 획기적으로 올리는 GRPO(Group Relative Policy Optimization) 파인튜닝 기법입니다.
  • 사용한 도구명: GRPO (Group Relative Policy Optimization), Qwen 3 4B, Unsloth, Google Colab (A100/T4 GPU), Hugging Face (open-r1/OpenR1-Math-220k).
  • 실습 절차:
    1. 구글 코랩 사본 저장 후 GPU를 연결하고 Unsloth 및 GRPO 관련 패키지를 설치.
    2. 1단계: Qwen 3 4B 모델에 추론 시작/끝(start working out, end working out, solution)의 표준 답변 형식을 선행 파인튜닝.
    3. 2단계: 수학 데이터셋(OpenR1-Math)을 로드하고 정답/형식 일치 여부를 검증하는 4가지 보상 함수(Reward Functions)를 설정.
    4. 질문 1개당 4개 답변을 동시 생성시켜 보상 점수를 매기는 GRPO 강화학습 100 스텝 진행.
    5. 학습 진행에 따라 리워드(Reward) 점수 변화를 확인하고, 파인튜닝된 어댑터를 GGUF로 변환하여 Hugging Face 업로드.
  • 주의점: GRPO 학습 초기(1~100 스텝)에는 보상 점수가 오르내리며 진동하므로, 안정적인 우상향 성능을 얻으려면 최소 150~200 스텝 이상의 학습 유지가 권장됩니다.
  • 활용 팁: 정답이 단 하나로 고정되지 않은 복잡한 스케줄링, 수학 문제, 추론 작업에서 AI의 답변 품질과 창의적인 해법 도출 능력을 비약적으로 끌어올릴 수 있습니다.
