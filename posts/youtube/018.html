오토코더_MCP 및 에이전트

출처: NotebookLM 「오토코더의 인공지능 및 업무 자동화 완벽 가이드」 라벨 'MCP 및 에이전트' (영상 9개, 중복 제외 8개) · 2026.10.04 생성

선택하신 8개 영상 소스의 내용을 바탕으로 요청하신 양식에 맞추어 작성한 요약본입니다.

챕터 1: AI 에이전트 쉽게 설명해드립니다 #shorts

  • AI 에이전트의 정의: 사용자가 목표를 제시하면 스스로 정보를 탐색하고 계획을 세워 실행까지 완수하는 똑똑한 AI 도우미입니다.
  • 주요 수행 업무: 스케줄 관리, 이메일 작성, 간단한 프로그래밍 지원 등 다방면의 실무 과제를 지원합니다.
  • 작동 형태: 미션을 부여하면 로봇이 해결책을 찾아 전달해 주는 개인 맞춤형 AI 비서 개념으로 동작합니다.
  • 디바이스 적용 동향: 최근 삼성 갤럭시 AI, 아이폰 등 최신 모바일 기기에도 에이전트 기술이 핵심 기반으로 탑재되고 있습니다.
  • 미래 발전 전망: AI 에이전트 기술의 고도화를 통해 머지않아 일상생활 전반의 편의성이 대폭 향상될 것으로 기대됩니다.

챕터 2: MCP 서버 10분 완성! 개념부터 Hello World까지 초보자도 따라하는 실전 가이드 🚀

  • 자체 MCP 서버 구성 이유: 스미더리 마켓의 보안 리스크를 방지하고 기업 전용 데이터 및 기능을 커스텀 개발하여 안전하게 활용하기 위해 직접 서버를 구축합니다.
  • 개발 도구 및 프레임워크: 클로드 데스크탑과 엔스로픽에서 개발한 파이썬 전용 MCP 구축 프레임워크인 FastMCP를 활용합니다.
  • MCP 툴(Tool)의 개념: LLM(대형 언어 모델)에서 직접 호출하여 실행할 수 있는 파이썬 함수 도구를 의미합니다.
  • 독스트링(Docstring)의 중요성: LLM이 도구의 기능과 역할을 정확히 파악하고 올바르게 선택·호출할 수 있도록 함수 내 지침을 명확히 작성해야 합니다.
  • FastMCP 환경 설치: 터미널 커맨드 창에서 pip install fastmcp 명령어로 라이브러리를 설치하여 서버 구축 환경을 준비합니다.
  • 파이썬 서버 스크립트 작성: FastMCP 객체를 선언하고 @mcp.tool 데코레이터와 독스트링을 적용하여 메시지를 반환하는 파이썬 함수를 작성합니다.
  • 클로드 데스크탑 설정 파일 연동: claude_desktop_config.json 설정 파일에 파이썬 커맨드 및 작성한 서버 스크립트 경로를 연동 등록합니다.
  • 서버 동작 실증: 클로드 데스크탑 커넥터에서 구축한 hello-world MCP 서버가 정상 연결되고, 사용자 질의 시 메시지 반환 함수가 성공적으로 실행됨을 검증합니다.

챕터 3: MCP 한 번에 이해하기｜AI가 도구를 쓰는 진짜 방법 (초보자 필수)

  • MCP(Model Context Protocol) 개념: AI 모델이 표준화된 프로토콜을 통해 외부 시스템, 데이터베이스, 도구를 직접 실행 및 제어할 수 있도록 돕는 규약입니다.
  • MCP의 출현 배경: AI 모델별(ChatGPT, Claude, Gemini 등)로 각각 연동 모듈을 중복 개발하던 비효율성을 통일된 규격 하나로 해결하기 위해 등장했습니다.
  • 표준 규약 비유 (USB 비유): 과거 제각각이던 외장 규격을 통일한 USB처럼, AI 도구 생태계의 통합 표준 역할을 수행합니다.
  • 스미더리(Smithery) 오픈 마켓: 타 개발자들이 구현한 다양한 MCP 서버를 탐색하고 즉시 다운로드하여 호출할 수 있는 마켓플레이스입니다.
  • 오픈 마켓의 보안 위험성: 스미더리의 검증되지 않은 서버 사용 시 백도어 침투 및 개인정보 유출 위험이 존재하므로 검증 수치가 높은 툴을 선택해야 합니다.
  • 기업 환경 구축 전략: 보안성이 최우선인 기업 환경에서는 외부 오픈 마켓 대신 파이썬 기반 자체 MCP 서버를 직접 개발하여 통제권을 확보합니다.
  • 클로드 데스크탑 동작 구조: 질의 수신 시 일반 LLM 답변과 MCP 서버를 통한 PC 내부 자원 제어 역할을 선택적으로 판단하여 동작합니다.

챕터 4: Smithery로 내 컴퓨터 1초 만에 자동 정리하는 법! (터미널 한 줄로 끝내는 파일 관리의 신세계)

  • 환경 및 툴 세팅: Node.js 런타임을 설치한 후 스미더리 마켓에서 검증된 Desktop Commander 앱 명령어를 복사하여 클로드 데스크탑에 연동합니다.
  • 테스트 파일 자동 생성: 제미나이 CLI(Gemini CLI)를 활용해 C드라이브 오토코더 폴더에 무작위 이름의 20개 테스트 파일(.pdf, .txt, .xlsx, .pptx)을 자동 생성합니다.
  • 클로드 커넥터 활성화: 클로드 데스크탑 앱 설정에서 Desktop Commander 커넥터를 활성화하여 PC 자원 접근 권한을 준비합니다.
  • 자연어 지시 실행: "폴더 위치에 있는 파일을 알아서 잘 분류하여 정리해 줘"라는 자연어 명령 한 마디를 전달합니다.
  • 에이전트 동작 및 파일 이동: AI 에이전트가 Documents, Presentation, Spreadsheet, Text 폴더를 자동 생성하고 확장자별로 파일을 일괄 이동시킵니다.
  • 결과 검증 및 자동 보고: 작업 완료 후 에이전트가 디렉토리 내부를 재확인하여 총 20개 파일이 카테고리별로 완벽히 정돈되었음을 사용자에게 보고합니다.
  • CLI와 MCP의 특성 비교: CLI 방식은 직접 명령어로 처리하여 속도가 빠르며, MCP 방식은 대화형 인터페이스에서 실행 전반을 에이전트가 알아서 제어해 주는 이점이 있습니다.

챕터 5: 아직도 엑셀 노가다 하세요? "말만 하면" 엑셀 정리가 완성됩니다! (feat. MCP 서버 & 바이브 코딩)

  • 기존 AI의 한계 극복: 일반 AI는 내 PC에 열려 있는 엑셀 통합문서 개체에 직접 접근할 수 없으나, 전용 MCP 서버를 활용하면 내 컴퓨터의 엑셀을 실시간 제어할 수 있습니다.
  • pyup-mcp-tools 파이썬 패키지 활용: 내 PC에 열린 엑셀 문서를 실시간으로 인식하고 조작해 주는 오픈소스 MCP 도구를 다운로드합니다.
  • 클로드 데스크탑 경로 연동: 다운로드받은 실행 파일 경로를 claude_desktop_config.json 설정 파일의 커맨드로 등록하여 연결합니다.
  • 열려 있는 엑셀 자동 감지: 현재 내 화면에 실행 중인 엑셀 창을 MCP 도구가 자동으로 찾아내어 내부 데이터 구조를 읽어옵니다.
  • 자연어 기반 엑셀 데이터 작성: 무작위 이름 생성, 이메일 주소 추가, LEFT 수식을 활용한 아이디 추출 작업을 자연어 대화로 자동 실행합니다.
  • 엑셀 서식 및 공식 적용: 특정 행 텍스트 볼드(Bold) 처리, SUM 공식을 이용한 합계 행 추가 및 연산 작업을 수행합니다.
  • 시트 생성 및 통계 연산 자동화: 월급 및 통계 시트를 새롭게 자동 생성하고 수식을 기입하여 합계와 평균값을 계산해 데이터 정리를 완성합니다.

챕터 6: 아직도 일일이 검색하세요? 노션(Notion)과 대화하는 나만의 AI 비서 만들기 (MCP 서버 초보자 가이드)

  • 노션 자동화 개요: 올인원 워크스페이스인 노션을 MCP 서버 및 API와 연동하여 AI 대화만으로 문서 작성 및 데이터베이스 관리를 자동화합니다.
  • 노션 API 통합 키 발급: 노션 개발자 사이트(Integrations)에서 새 통합을 만들고 프라이빗 API 시크릿 키를 발급받아 기본 권한을 설정합니다.
  • 클로드 데스크탑 설정 파일 연동: GitHub의 노션 MCP 서버 지침에 따라 claude_desktop_config.json에 API 키와 서버 설정을 기입합니다.
  • 자연어 기반 페이지 자동 생성: "내 노션에 MCP에 대해 작성해 줘" 질의 시 API 연동을 통해 노션 워크스페이스에 새 페이지를 생성하고 내용을 자동 기입합니다.
  • 개념 비교 문서 자동 작성: MCP와 A2A 개념을 비교하는 요청 시 최신 분석 데이터를 생성하여 노션 상의 별도 페이지로 구조화해 저장합니다.
  • 노션 내부 데이터 검색 및 읽기: 내 노션에 저장된 특정 키워드(MCP 특징)를 탐색하여 해당 문장을 정확히 읽어와 대화창에 반환합니다.
  • 노션 페이지 자동 삭제: "해당 내용이 담긴 페이지를 삭제해 줘"라는 명령어만으로 불필요한 노션 페이지를 휴지통으로 이동시켜 자동 정리를 완료합니다.

챕터 7: 클로드가 내 PC를 자동 정리? 😱 파일 정리 AI 비서 만들기 | MCP 서버 구축 완벽 가이드

  • 실습 목적: 외부 마켓을 쓰지 않고 보안성이 확보된 자체 파이썬 MCP 서버 스크립트(file_handle.py)를 직접 개발하여 작동시킵니다.
  • 필수 개발 환경 준비: 클로드 데스크탑, Node.js 런타임, pip install fastmcp 파이썬 패키지를 설치합니다.
  • 파일 핸들링 함수 개발: 특정 지정 폴더 내 파일 목록 조회(list_items), 파일 읽기(read_file), 파일 쓰기(write_file), 폴더 관리(manage_folder) 함수를 작성합니다.
  • 독스트링 및 데코레이터 적용: AI가 각 함수의 기능을 정확히 파악할 수 있도록 상세 설명과 @mcp.tool 데코레이터를 지정합니다.
  • 클로드 데스크탑 연동: 타 커넥터를 끄고 내가 만든 file_handle MCP 서버 실행 명령을 JSON 설정 파일에 등록합니다.
  • 파일 목록 조회 및 쓰기 실행: C드라이브 오토코더 테스트 폴더 내 목록을 조회하고, hello_coder.txt 파일에 텍스트를 자동 작성해 저장합니다.
  • 폴더 자동 생성 검증: 오토코더라는 이름의 신규 디렉토리 생성 명령 실행 시 실제 내 PC에 폴더가 즉시 생성됨을 확인합니다.

챕터 8: 🚨내 PC를 직접 조종하는 AI가 등장했습니다! '오픈클로(OpenClaw)' 작동 원리부터 설치, 텔레그램 연동까지 한 번에 끝내기

  • 오픈클로(OpenClaw) 소개: 오스트리아 엔지니어가 개발한 오픈소스 AI 에이전트로, 내 PC OS의 모든 관리자 제어 권한을 위임받아 수행하는 실행형 비서입니다.
  • 작동 원리 및 게이트웨이 역할: 사용자 지시 수신 시 LLM 두뇌(OpenAI API 등)와 내 PC 시스템, 웹 서비스, 노션 등을 유기적으로 연결하는 게이트웨이 역할을 합니다.
  • 설치 및 온보딩 세팅: Node.js 환경에서 npm install -g openclaw 설치 후 openclaw onboard 명령어로 API 키 및 시스템 환경을 세팅합니다.
  • 텔레그램(Telegram) 연동: 텔레그램 봇파더(BotFather)를 통해 생성한 봇 토큰을 등록하고 관리자 승인 페어링을 통해 대화창과 연결합니다.
  • 프로그램 직접 제어 시연: 텔레그램 메시지 지시만으로 내 PC의 메모장을 실행해 텍스트를 작성하거나 엑셀(Excel) 프로그램을 직접 제어합니다.
  • 보안 위험성 및 유의사항: OS 제어권을 통째로 위임받으므로 잘못된 프롬프트 전달 시 파일 삭제나 시스템 장애 위험이 있어 보안 관리가 필수적입니다.
  • 안전한 사용 가이드: 시스템 파괴 위험을 제어하기 위해 개인 업무용 메인 PC보다는 버추얼 머신이나 컨테이너 등 격리된 샌드박스(Sandbox) 환경에서의 실행을 권장합니다.

라벨 종합 정리

  • 핵심 주제: AI 에이전트, MCP(Model Context Protocol), 오픈클로(OpenClaw) 등 차세대 표준 규약 및 플랫폼을 활용하여 내 PC 자원(파일, 엑셀, 노션 등)과 AI 모델을 연동하는 업무 자동화 구축법을 다룹니다.
  • 개발 및 보안 전략: 스미더리 마켓을 활용한 빠른 설치 방식과 기업 보안성·안정성을 확보할 수 있는 자체 파이썬 MCP 서버 개발 방식을 비교하여 최적의 에이전트 구현 환경을 제시합니다.
  • 미래 관점: 단순 대화형 AI를 넘어 지시에 따라 파일 분류, 문서 수정, 프로그램 직접 실행까지 대행하는 AI 비서 생태계의 실무 적용과 안전한 샌드박스 운용의 필요성을 강조합니다.
