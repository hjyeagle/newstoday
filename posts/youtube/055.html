1. (쉬운 실습) 클로드 코드, Agent들을 내 마음대로 지휘하다! (에이전트 오케스트레이션, AI Agent Orchestration)

  • 핵심 요약 및 개요: 클로드 코드를 활용해 여러 AI 에이전트를 오케스트라 지휘자처럼 제어·조정하는 '에이전트 오케스트레이션(AI Agent Orchestration)' 시스템을 구축하고, 수업 자료 생성을 자동화하는 실습입니다.
  • 사용한 도구명: Claude Projects / Gems / GPTs (스타트 프롬프트 제작), Claude Desktop App (Code 기능), VS Code.
  • 실습 절차:
    1. Claude Projects에 전용 지침을 입력해 에이전트와 스킬 구조가 포함된 '스타트 프롬프트'를 생성합니다.
    2. 스타트 프롬프트를 복사해 Claude 데스크톱 앱의 Code 탭(로컬 폴더 지정)에 입력합니다.
    3. 클로드 코드가 오케스트레이터 및 서브 에이전트 5개와 6개의 스킬 파일을 지정 폴더에 자동 생성합니다.
    4. 대화창에서 "중학교 과학 광합성 수업 자료를 만들어줘"라고 지시합니다.
    5. 에이전트들이 병렬로 작동하여 수업 계획서, 워크시트, 퀴즈 등을 동시에 생성하는 것을 확인합니다.
  • 주의점: 초기 설계도 역할을 하는 '스타트 프롬프트'가 구체적이어야 에이전트와 스킬 파일이 오차 없이 정확하게 구성됩니다.
  • 활용 팁: 개별 에이전트를 따로 불러올 필요 없이 오케스트레이터가 요청을 분석해 일괄 병렬 처리해주므로, 단 한 번의 질문으로 다양한 형태의 산출물을 한눈에 도출할 수 있습니다.

2. (실습) Agent Builder 배포하는 방법 (n8n, make, zapier 대체 서비스 등장!)

  • 핵심 요약 및 개요: OpenAI의 노코드 자동화 도구인 Agent Builder의 연동법을 익히고, 이를 바이브 코딩 및 OpenAI API 키와 결합하여 셰익스피어 시험 문제 생성 웹앱으로 배포하는 전체 과정을 다룹니다.
  • 사용한 도구명: OpenAI Agent Builder (platform.openai.com/agent-builder), Project Gutenberg (원문 자료), OpenAI API Key, Cursor (바이브 코딩).
  • 실습 절차:
    1. platform.openai.com/agent-builder에 접속하여 새 워크플로우를 만듭니다.
    2. '자료 수집 에이전트' 노드를 가져와 지침과 Project Gutenberg 파일 검색(File Search) 툴을 등록합니다.
    3. '문항 생성 에이전트'와 'User Approval' 노드를 순서대로 연결하고 워크플로우를 게시(Publish)합니다.
    4. 추출된 에이전트 SDK 코드를 복사해 Cursor 등 바이브 코딩 툴에 전달하고 웹 사이트 코드를 생성합니다.
    5. 배포된 웹 사이트에 OpenAI API 키를 입력해 학생용 시험지, 답안지, 교사용 가이드가 포함된 시험 문제를 자동 출력합니다.
  • 주의점: Agent Builder 웹 화면의 프리뷰나 임베드를 이용하려면 조직 신분증 인증(Verification) 절차가 요구될 수 있습니다.
  • 활용 팁: n8n이나 Make 같은 외부 서비스 없이 OpenAI 플랫폼 내에서 노드로 연결된 에이전트 워크플로우를 구축할 수 있어 개발 체계가 정돈됩니다.

3. [클로드 Cowork] 매일 같은 시각에 뉴스레터 자동 생성하는 법 (작업 예약 기능)

  • 핵심 요약 및 개요: Claude 데스크톱 앱의 Cowork 기능과 작업 예약(Schedule) 설정을 결합하여, 폴더 내 부동산 엑셀 데이터를 분석하고 매일 오전 9시 최신 뉴스 기반 뉴스레터를 자동 발행하는 시스템을 구축합니다.
  • 사용한 도구명: Claude Desktop App (Cowork), 한국은행/KB 부동산 CSV 데이터 (12개), 인터넷 웹 검색, 작업 예약 기능 (/schedule).
  • 실습 절차:
    1. 부동산 관련 CSV 데이터 파일 12개가 담긴 로컬 폴더를 만든 후 Claude Cowork에서 작업 폴더로 지정합니다.
    2. Cowork에게 해당 폴더 데이터를 분석하여 '원페이지 보고서 및 뉴스레터 스킬'을 자율 생성하도록 지시합니다.
    3. 스킬을 통해 12개 CSV 각각의 요약 보고서와 한국 부동산 종합 분석 보고서를 도출합니다.
    4. 매일 아침 최신 부동산 뉴스를 검색해 보유 엑셀 데이터와 대조·분석하는 뉴스레터 프롬프트를 테스트합니다.
    5. "매일 오전 9시에 자동 실행 스케줄을 설정해줘"라고 요청하여 예약 작업을 완료합니다.
  • 주의점: 정해진 시각에 예약 작업이 실행되려면 해당 컴퓨터가 켜져 있어야 하며, Cowork가 폴더 내부 파일을 수정/삭제할 수 있으므로 원본 데이터 백업이 필수적입니다.
  • 활용 팁: 매일 실시간 검색된 뉴스 트렌드와 사전에 넣어둔 정량적 데이터 통계를 대조 분석하여 인사이트를 도출하므로, 시황 보고서 작성 자동화에 유용합니다.

4. [클로드 Skills] 나만의 AI 직원에게 업무 인수인계 하는 법

  • 핵심 요약 및 개요: 클로드의 스킬(Skills) 기능을 활용하여 내 업무 스타일에 맞춘 재사용 가능 지침서(.zip 모듈)를 만들고, AI 인수인계서 형태로 등록하여 대화창에서 자유롭게 불러와 사용하는 기법을 소개합니다.
  • 사용한 도구명: Claude (Projects / Skills / Profile Settings), 스킬 제작 전문팀 프롬프트 (.txt), .zip 모듈 파일.
  • 실습 절차:
    1. Claude에서 '스킬스 제작 전문팀' 프로젝트를 생성하고 전용 지침(.txt)을 세팅합니다.
    2. 기존에 만들어둔 PPT 파일이나 유튜브 대본 자막 예시 파일 3개를 첨부하여 내 스타일을 분석하게 합니다.
    3. 프로젝트 팀이 가이드라인(어조, 금지사항 등)을 적용해 생성해 준 .zip 스킬 파일을 다운로드합니다.
    4. Claude 프로필 -> 설정 -> 기능 -> 스킬 업로드 메뉴로 이동하여 다운로드한 .zip 스킬을 등록합니다.
    5. 새 대화창에서 "필로소피 스타일로 대본을 써줘"라고 요청하면 등록된 스킬을 자동 인식하여 맞춤형 대본을 생성합니다.
  • 주의점: 너무 많은 스킬을 동시에 활성화해 두면 클로드가 작업 시 혼란을 겪을 수 있으므로 사용하지 않는 스킬은 설정의 토글 스위치로 꺼두어야 합니다.
  • 활용 팁: 커스텀 인스트럭션이 모든 대화에 일률 적용되는 것과 달리, 스킬은 대화 중 필요할 때만 명칭이나 맥락으로 불러와 일관된 업무 품질을 유지할 수 있습니다.

5. AI Agent 이메일 자동화 (Flowise AI)

  • 핵심 요약 및 개요: 오픈소스 AI 에이전트 빌더인 Flowise AI를 이용해 Claude 3.5 Sonnet, Serp API(구글 검색), Gmail 연동(Composio)을 결합하고 실시간 검색 기반 이메일 자동 전송 에이전트를 구축하는 실습입니다.
  • 사용한 도구명: Flowise AI, Claude 3.5 Sonnet (Anthropic Console API Key), Serp API, Composio (Gmail Integration).
  • 실습 절차:
    1. Flowise AI에 접속하여 'AgentFlow' 새 프로젝트를 생성하고 시작 노드를 배치합니다.
    2. AI 모델로 Anthropic Claude 3.5 Sonnet을 선택하고 API 키 크리덴셜을 등록합니다.
    3. 구글 검색용 Serp API 노드를 추가하고 계정 API 키를 연동합니다.
    4. Composio 서비스를 통해 Gmail 커넥터를 승인(Connect)하고 'Send Gmail' 툴 노드로 플로우와이즈와 연결합니다.
    5. 채팅창에 "손흥민 선수의 커리어를 검색해서 내 이메일로 작성해 보내줘"라고 요청 후 이메일 수신을 확인합니다.
  • 주의점: Composio 연동 시 Gmail 계정 접근 권한 승인을 빠짐없이 체크해야 하며, 최신 3.5 Sonnet 모델 등 사용 시 API 비용이 발생할 수 있어 한도를 확인해야 합니다.
  • 활용 팁: 단순 문장 생성을 넘어 웹 실시간 정보 검색과 이메일 실제 발송 툴이 직관적인 노드로 연결되어 있어, 정기 리포트 발송 업무를 손쉽게 오토메이션할 수 있습니다.

6. AI Agent, Operator 진짜 놀랍네요..

  • 핵심 요약 및 개요: OpenAI가 공개한 CUA(Computer Using Agent) 기반 웹 자동화 에이전트 Operator(운영자)의 주요 기능, 시각적 브라우저 제어 시연, 'Take Control' 기능 및 파급력을 분석합니다.
  • 사용한 도구명: OpenAI Operator (ChatGPT Pro Plan 전용), 야놀자 / 아고다 / 오픈테이블 / 인스타카트.
  • 실습 절차:
    1. ChatGPT Pro 요금제 계정에서 '운영자(Operator)' 모드를 선택하여 실행합니다.
    2. 야놀자 등의 예약 사이트를 고르고 "경주 2박 3일 오션뷰 숙소를 찾아줘"라고 요구사항을 입력합니다.
    3. Operator가 시각적 브라우저 화면을 직접 보며 새로고침, 날짜 선택, 오션뷰 필터링을 자율 수행하는 과정을 관찰합니다.
    4. 중간에 사람이 직접 개입할 때 'Take Control' 버튼을 눌러 로그인을 수행한 뒤 'Return Control'로 업무 인수인계를 전달하여 재개합니다.
    5. 최종 결정 단계에서 승인(Allow)을 받아 결제 전 단계까지 예약을 대행 완료시킵니다.
  • 주의점: 아직 리서치 초기 단계로 웹 요소 인식에 다소 시간이 걸리거나 오류가 날 수 있으며, 로그인/결제 등 중요 개인정보는 사람이 직접 입력해야 합니다.
  • 활용 팁: AI가 시각적으로 브라우저를 마우스와 키보드로 제어하므로, 사용자는 자리를 비우고 알림(Notification)이 올 때만 접속해 승인해주면 되는 개인 비서 서비스를 경험할 수 있습니다.

7. AI Agent가 내 자료를 참고해서 이메일을 보내줍니다! (Flowise AI Document store)

  • 핵심 요약 및 개요: Flowise AI의 Document Store 기능과 Supabase(PostgreSQL Vector DB) 및 Google Embedding Gemma를 연동하여, 내 사내 보도자료/PDF 데이터를 RAG 방식으로 읽어 정돈된 요약 이메일을 자동 발송하는 실습입니다.
  • 사용한 도구명: Flowise AI (Document Store), Supabase (PostgreSQL), Google AI Studio (Gemini Embedding), Composio (Gmail API).
  • 실습 절차:
    1. Flowise AI 메뉴에서 'Document Store'를 생성하고 한국은행 기업경기조사 보도자료(PDF)를 업로드합니다.
    2. Text Splitter로 청크(Chunk Size 1000) 분할 후 Google Gemini Embedding 모델과 Supabase 데이터베이스 연결 정보를 입력합니다.
    3. 업서트(Upsert)를 실행하여 PDF 문서 내용을 벡터 수치로 분할·저장합니다.
    4. 에이전트 플로우로 돌아와 해당 Document Store를 널리지(Knowledge) 노드로 연결합니다.
    5. 대화창에 "Document Store에 넣은 자료를 요약해서 이메일로 보내줘"라고 명령하여 메일 수신을 확인합니다.
  • 주의점: Supabase 커넥션 세팅 시 DB 비밀번호 및 포트번호(6543 등)를 정확히 기입해야 하며, 문서 분할 청크 크기와 오버랩 설정을 적절히 해주어야 답변 누락이 없습니다.
  • 활용 팁: 챗봇 형태의 RAG를 넘어, 내 문서 원본을 바탕으로 핵심 인사이트를 요약해 즉시 Gmail로 발송하는 고도화된 업무 자동화 파이프라인을 구축할 수 있습니다.

8. AI의 생산성을 높이는 방법 (Agentic Workflow)

  • 핵심 요약 및 개요: 앤드류 응(Andrew Ng) 교수의 강연을 바탕으로, 단판 답변(Zero-shot) 대신 성찰·도구사용·기획·협업으로 구성된 반복 개선 구조 Agentic Workflow의 개념과 적용 효과를 파악하고 GPTs 실습을 진행합니다.
  • 사용한 도구명: Agentic Workflow (Reflection, Tool Use, Planning, Multi-Agent Collaboration), ChatGPT (GPTs).
  • 실습 절차:
    1. 앤드류 응 교수의 4가지 에이전틱 디자인 패턴(Reflection, Tool Use, Planning, Multi-Agent Collaboration) 이론을 분석합니다.
    2. GPTs 생성 화면에서 김태호(가이드), 이미린(리뷰), 최진수(완성) 등 멀티 에이전트 역할을 하나의 인스트럭션으로 설정합니다.
    3. 주제(예: AI 교육 영향 콘텐츠 기획)를 던지면 초고 작성 -> 비판적 검토 -> 개선안 제시 프로세스를 단계별로 거치게 합니다.
    4. 팀원 간 대화 및 검토 과정을 통해 초안보다 정교하고 논리적인 최종 산출물 및 출처 링크를 도출합니다.
    5. GPT 3.5 모델에 에이전틱 워크플로우를 적용하는 것만으로도 Zero-shot GPT-4의 답변 품질을 능가함을 실험 결과로 확인합니다.
  • 주의점: 한 번의 질의응답으로 완료되지 않고 여러 번의 추론 및 수정 루프를 거치므로 토큰 소모량과 응답 대기 시간이 늘어날 수 있습니다.
  • 활용 팁: 더 비싼 모델을 쓰기보다 저렴한 모델이라도 스스로 검토(Reflection)하고 도구를 쓰도록 프롬프트를 설계하면 AI 답변의 신뢰도와 깊이를 비약적으로 올릴 수 있습니다.

    4. 5분 이내에 연이어 추가 질문("AI 활용 정책 대응 방안은?")을 보냈을 때 input_tokens: 0으로 캐시를 즉시 재사용함을 확인합니다.
    5. 5분 경과 후 캐시 데이터가 휘발(Expiring)되면 다시 16,116개 인풋 토큰이 차감되는 라이프사이클 동작 메커니즘을 점검합니다.
  • 주의점: 200페이지가 넘는 초대형 PDF는 API 타임아웃이 발생할 수 있으므로 적절한 분량(10~50페이지 내외)으로 시도해야 하며, 5분간 질문이 없으면 캐시가 자동 삭제됨에 유의해야 합니다.
  • 활용 팁: 단발성 질문보다는 5분 이내에 보고서나 규정집 PDF에 대해 다각도의 연속 질의응답을 이어나갈 때 캐싱 효율이 극대화됩니다.

클로드를 좋아하는 네 번째 이유 : AI Agent 오케스트레이션

  • 핵심 요약 및 개요: 지휘자 역할을 하는 오케스트레이터(Orchestrator) 에이전트와 분야별 서브 에이전트(리서치, 스크립트, 썸네일, SNS)를 클로드 프로젝트 및 클로드 데스크톱 앱(Code)으로 구축하여, 한 번의 명령으로 수업/콘텐츠 자산을 병렬 처리로 제작하는 기법입니다.
  • 사용한 도구명: Claude Projects (Start Prompt 팀), Claude Desktop App (Code 모드 / 로컬 환경), Cursor / VS Code, Markdown / Text Output.
  • 실습 절차:
    1. 클로드 Projects 지침에 스킬풀 에이전트 프롬프트 제작 지침(.txt)을 입력합니다.
    2. "AI 교육 유튜브 채널 운영자를 위한 에이전트 오케스트레이션 시스템을 짜줘"라고 요청하여 스타트 프롬프트(Start Prompt)를 생성합니다.
    3. 복사한 스타트 프롬프트를 클로드 데스크톱 앱의 Code 탭(로컬 지정 폴더)에 입력합니다.
    4. 클로드 코드가 5개 에이전트 파일과 5개 스킬 파일을 로컬 폴더에 병렬로 자동 생성합니다.
    5. "바둑 기사의 AI 학습 원리를 교육에 적용하는 콘텐츠를 만들어줘"라고 지시하면 오케스트레이터가 리서치->스크립트->썸네일->SNS 글을 병렬로 완성해 out/ 폴더에 저장합니다.
  • 주의점: 시작점인 스타트 프롬프트(Start Prompt)의 설계가 구체적이고 정교해야 오케스트레이터가 하위 에이전트와 스킬을 오류 없이 올바르게 생성합니다.
  • 활용 팁: 수동으로 에이전트를 하나씩 호출할 필요 없이 단 한 번의 자연어 지시만으로 다양한 형태의 연관 콘텐츠들을 병렬로 수 분 만에 한곳에 도출할 수 있습니다.

  • 사용한 도구명: Claude Desktop App (Cowork 모드), Local Work Folder, MS Word (.docx), Projects Context / Skills.
  • 실습 절차:

    2. 작업 폴더에 책 원고 챕터 1~8 워드 파일들(.docx)을 세팅합니다.

    4. Cowork가 폴더 구조를 파악하고 챕터별 분석 후 서브 에이전트들을 동시 구동해 병렬로 리라이팅 작업을 수행합니다.
    5. 작업 폴더 내에 완성된 V2 버전의 업그레이드 원고 파일들이 새로 생성되었음을 확인합니다.
  • 주의점: 코워크는 지정된 로컬 폴더 내 기존 파일을 직접 수정하거나 변경할 수 있으므로, 실행 전 중요한 원본 파일은 반드시 백업 폴더로 복사해 두어야 합니다.
  • 활용 팁: 엑셀 데이터 원장 정리, 여러 워드 보고서 통합, 대량 파일 이름 변경 등 번거롭고 정형화된 파일 처리 작업을 알아서 처리해 주는 AI 전담 직원으로 활용 가능합니다.

클로드를 좋아하는 세 번째 이유 : Skills 스킬즈

  • 핵심 요약 및 개요: 내가 자주 수행하는 업무 규칙, 가이드라인, 템플릿 양식을 클로드 스킬(.zip) 모듈로 가공하여 업로드하고, 어떤 대화 세션에서든 불러와 일관된 품질로 반복 업무를 처리하게 만드는 인수인계 시스템입니다.
  • 사용한 도구명: Claude (Projects / Settings / Skills Upload), 스킬 제작 전문팀 프롬프트 (.txt), .zip 모듈 파일, 유튜브 대본 텍스트/PPT.
  • 실습 절차:
    1. 클로드 Projects에 스킬 제작 전문팀 지침(.txt)을 입력해 프로젝트를 생성합니다.
    2. 내 유튜브 우수 대본 샘플 3개를 제공하고 "내 스타일을 분석해 스킬로 만들어줘"라고 요청합니다.
    3. 프로젝트 팀이 금기사항(딱딱한 문어체 금지 등)과 톤앤매너가 담긴 .zip 스킬 파일을 도출합니다.
    4. 클로드 프로필 -> 설정 -> 기능 -> '스킬 업로드' 메뉴에서 다운로드한 .zip 파일을 연동합니다.
    5. 새 대화창에서 "필로소피 스타일로 C댄스 2.0 대본을 작성해줘"라고 지시하면 등록된 스킬을 자동 탐색해 인수인계받은 대로 대본을 완성합니다.
  • 주의점: 필요 이상의 너무 많은 스킬을 한 번에 활성화해 두면 클로드가 지침 간 혼선을 겪을 수 있으므로 사용하지 않는 스킬은 토글 버튼으로 비활성화해야 합니다.
  • 활용 팁: 대화 세션마다 긴 가이드라인을 반복 입력할 필요 없이 스킬로 한 번 업로드해 두면 언제든 동일한 서식과 스타일로 산출물을 얻을 수 있습니다.

  • 실습 절차:

    2. 터미널에 claude remote-control 명령어 입력 후 스페이스바를 눌러 QR코드를 출력시킵니다.
    3. 스마트폰의 카메라나 클로드 앱으로 터미널의 QR코드를 스캔하여 세션을 연결합니다.
    4. 스마트폰 대화창에 "영어 학습 웹앱을 만들어줘"라고 자연어로 지시합니다.
    5. 외부에서 산책하며 스마트폰으로 응답 및 승인을 진행하면, PC의 로컬 폴더에 완성된 index.html 웹 사이트 파일이 자동 생성됩니다.
  • 주의점: Remote Control 세션이 유지되려면 내 PC가 켜져 있고 클로드 코드가 백그라운드에서 구동 중이어야 하며, Max/Pro 요금제 계정이 요구됩니다.
  • 활용 팁: PC 앞을 비우더라도 산책이나 이동 중에 스마트폰으로 로컬 개발 세션을 원격 조작하고 결과를 실시간 점검할 수 있습니다.
