퍼플렉시티 Search API 공개! 리서치 효율 높이는 3가지 활용법

  • 리서치 프로세스의 세분화 및 모듈화: AI에게 리서치 전체를 일임할 때 발생하는 출처 통제 불능, 최신 정보 누락, 환각 문제 해결을 위해 검색 쿼리 추출, 출처 저장, 본문 분석, 요약 단계를 쪼개어 자동화합니다.
  • n8n 기반 퍼플렉시티 Search API 연동: n8n 내에 내장된 데이터 테이블(Data Table)에 프롬프트와 케이스별 쿼리를 저장하고, HTTP 리퀘스트 노드로 Search API를 직접 연동해 재현성 높은 검색을 수행합니다.
  • 활용법 1 - 멀티 키워드 검색 및 스니펫 요약: 키워드별 관련 사이트(최대 20개)와 스니펫(Snippet) 정보를 수집하여 구글 시트에 출처를 아카이브하고, ChatGPT(GPT-4o-mini)로 핵심 브리핑 리포트를 요약 생성합니다.
  • 활용법 2 - 제미나이 URL 컨텍스트 기반 본문 정독: 수집된 URL 리스트를 제미나이(Gemini) API의 URL 컨텍스트 툴로 전달하여, AI가 사이트에 직접 접속해 본문 전체를 정독한 뒤 세밀한 비교 분석 보고서를 작성합니다.
  • 활용법 3 - 신뢰할 수 있는 도메인 기반 딥리서치: 코드 노드로 두 번 이상 등장하거나 허용된 도메인을 필터링한 후, 퍼플렉시티 딥리서치(Deep Research) 비동기식(A-sync) 모드로 타임아웃 없이 심층 분석 리포트를 도출합니다.
  • 비동기식(A-sync) 루프 체크 및 안정적 결과 수집: 시간이 오래 걸리는 딥리서치 요청 시 웨이트(Wait) 노드와 조건문 루프를 구성해 처리 완료 상태(Completed)를 주기적으로 확인한 후 최종 결과를 시트에 저장합니다.
  • 생산성을 높이는 정밀 시스템 구축: AI에게 막연히 맡기지 않고 리서치 단계를 수동 컨트롤 가능한 구조로 구축함으로써 팩트체크 시간을 단축하고 리서치의 신뢰도를 극대화합니다.

  • 퍼플렉시티 코맷(Comet)의 개념: 단순 웹페이지 열람 도구를 넘어 사용자의 의도를 파악하고 웹 브라우저 자체를 조작하는 능동형 AI 에이전틱(Agentic) 브라우저입니다.
  • 구글 워크스페이스(지메일·캘린더) 연동: 캘린더와 지메일을 연동하여 브라우저 대화창에서 하루 일정 확인, 미팅 중복 감지 및 자동 시간 변경, 이메일 문의 리스트업 및 회신을 대화형으로 완결합니다.
  • 우측 AI 어시스턴트(Option+A)를 통한 메일 답장: 지메일 문의 화면에서 단축키로 어시스턴트를 호출하여 단가 및 일정 지침만 전달하면 본문 내용을 파악한 맞춤형 메일 초안 작성 및 즉시 발송을 수행합니다.
  • 웹페이지 및 SNS(X) 다중 스크롤 요약: 열려 있는 탭 내 테크크런치 상위 10개 기사 요약 및 엔트로픽 X(트위터) 계정에 직접 접속해 스크롤을 내리며 최근 20개 포스트 핵심을 별도 크롤러 없이 즉시 요약합니다.
  • 유튜브 영상 및 댓글 반응 다각도 분석: 20분 분량의 유튜브 영상 핵심 요약뿐만 아니라 수백 개의 댓글을 긍정 반응과 부정 피드백으로 정밀하게 분류·요약하여 콘텐츠 기획에 활용합니다.
  • 자연어 명령 기반 탭 관리: 리서치 중 난잡하게 열린 여러 브라우저 탭 중 특정 플랫폼(X 등) 관련 탭을 자연어 한 줄로 일괄 정리·닫기를 실행합니다.
  • 에이전틱 브라우징의 미래와 제약: 월 200달러 맥스 플랜 전용 제공 및 프라이버시 권한 제공 필요성의 한계가 있으나, 브라우저가 지능형 업무 파트너로 변화하는 트렌드를 선도합니다.

챗GPT를 대체할 리서치 도구? 퍼플렉시티의 진짜 강점 (신규 기능 포함)

  • 앤서 엔진(Answer Engine) 중심의 리서치 특화: 구글 검색처럼 여러 링크를 직접 들어가지 않고, GPT-4o나 클로드 3.5 소넷 기반의 웹 서치 포맷을 통해 검증된 출처와 함께 완성형 요약 답변을 즉시 제공합니다.
  • 프로 서치(Pro Search) 및 포커스 모드: 프로 서치 구동 시 2배 이상의 출처를 정밀 탐색하며, 학술 논문, 유튜브 영상, 레딧 토론 등 특정 영역으로 검색 범위를 한정하는 포커스 모드를 지원합니다.
  • 목적 기반 공간(Space) 및 커스텀 인스트럭션: 책 추천, 테크 뉴스, 마켓 리서치 등 주제별 전용 공간을 개설하고 커스텀 지침 및 개인 프로필 정보를 입력해 맞춤형 정보 수집 환경을 구축합니다.
  • 커스텀 웹 도메인(Custom Web Domain) 제어: 스페이스 내에 신뢰할 수 있는 특정 웹사이트 도메인을 최대 10개까지 추가하고 일반 웹 검색을 끔으로써 내가 지정한 고품질 소스 내에서만 리서치를 진행하도록 통제합니다.
  • 관련 추가 질문(Follow-up)을 통한 심층 탐색: 답변 하단에 자동 추천되는 꼬리 질문들을 클릭함으로써 질문 작성 스킬이 부족하더라도 시장 규모, 성장 요인, 소비자 특징까지 깊이 있게 다단계 리서치를 이어갑니다.
