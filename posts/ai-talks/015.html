빌더조쉬 - 클로드 코드 마케팅 에이전트 팀 100% 자동화

영상 정보

  • 영상 URL: https://youtu.be/6MJ-pmckowQ?si=JZT3hU09CaW6Kuf-
  • 구분: 클로드

요약

"실행 자체는 5%, 퀄리티를 결정하는 하네스 세팅에는 95%의 시간을 써야 한다"는 원칙 아래, 클로드 코드로 마케팅 팀 전체(뉴스레터·카드뉴스·PPT·소셜 포스팅)를 자동화하는 세팅 과정을 처음부터 끝까지 녹화해 보여주는 영상.

폴더 구조 설계: context 폴더에는 브랜드 가이드라인·디자인 스타일 가이드·비즈니스 맥락을 담은 MD 파일을, templates 폴더에는 카드뉴스·PPT·뉴스레터·유튜브 썸네일 템플릿을 넣는다. 자사 웹사이트를 캡처해 클로드에 넣고 "브랜드 가이드라인, 디자인 스타일 가이드, 비즈니스 맥락 세 가지를 MD 파일로 만들어줘"라고 요청해 맥락 파일을 자동 생성한다.

CLAUDE.md의 역할: 프로젝트 전체의 폴더 구조, 각 에이전트의 역할과 사용해야 할 스킬, 작업 규칙(SOP)을 정의한 문서로, 이게 없으면 서브에이전트를 아무리 잘 만들어도 클로드 코드가 작업 순서를 헷갈려한다고 강조한다.

공식 스킬과 이미지 MCP 활용: 앤트로픽이 공식 제공하는 스킬(PPTX, DOCX, PDF 등)을 마켓플레이스에서 설치해 산출물 포맷을 표준화하고, 나노바나나(재미나이 이미지) MCP를 연결해 카드뉴스 이미지를 생성한다. 클로드 코드가 직접 이미지를 만드는 것보다 MCP를 붙이는 쪽이 훨씬 빠르고 품질도 좋다는 결론을 제시한다.

서브에이전트 팀 구성: "클로드 코드의 공식 가이드라인을 따라 마케팅 에이전트 팀 계획도를 제안해줘"라고 요청하면 리서치→콘텐츠 제작→디자인→검수의 4단계 파이프라인을 스스로 설계해준다. 이후 CLAUDE.md에 "어떤 작업엔 어떤 에이전트를 쓸지"를 정하는 라우팅 룰을 추가하는 것이 중요하다고 설명한다.

병렬 실행과 자동 배포: "모든 에이전트 팀을 가동해 뉴스레터·카드뉴스·유튜브 썸네일·프레젠테이션을 한 번에 만들어줘"라고 지시하면 약 10분 만에 전체 산출물이 동시에 생성된다. 마지막으로 버퍼(Buffer) API를 .env 파일에 저장해 연동하면, 만들어진 카드뉴스를 지정한 날짜·시간에 소셜 미디어에 예약 포스팅까지 자동으로 처리할 수 있음을 실제로 시연한다. API 키는 절대 외부에 노출하면 안 된다는 점을 반복 강조한다.

정리: ① 컨텍스트 폴더 세팅 → ② 스킬 설치 → ③ CLAUDE.md(SOP) 작성 → ④ 서브에이전트 생성·개별 테스트 → ⑤ 버퍼 API로 자동 배포, 총 5단계로 마케팅 에이전트 팀 구축 과정을 요약한다.
