노트북LM 무료 활용법 - 핵심 기능 + 크롬 확장프로그램 7가지 (어나더 AI)

영상 정보

  • 영상 URL: https://youtu.be/dAkT6IecuGQ?si=G-21hJ3UjE41J_P1
  • 구분: 제미나이

요약

[결론] 제미나이 노트북(구 노트북LM)은 단순 요약도구에서 자료 없이도 웹을 직접 조사해 보고서·동영상·오디오·플래시카드까지 만들어주는 자율형 AI 연구 파트너로 진화했으며, 여기에 7가지 크롬 확장프로그램을 결합하면 자료 수집·정리 시간을 크게 줄일 수 있습니다.

[핵심 근거]

  1. 딥 리서치 기능: 소스 추가 없이도 질문을 분석·계획·검색·추론·보고의 4단계 프로세스로 자율적으로 수행하며(패스트는 빠른 팩트체크용, 딥은 심층 비교분석용), 5개 이상 소스 수집 시 자동 라벨링 기능이 문맥별로 그룹화해 답변 정확도를 높임.
  2. 스튜디오 다중 출력: 보고서(브리핑문서/학습가이드/블로그), 데이터표, 인포그래픽(스타일 선택 가능), 발표자 슬라이드, 오디오 오버뷰(대화·브리프·크리틱·디베이트 모드), 동영상 개요(설명/요약, 한국어 지원), 플래시카드·퀴즈까지 하나의 소스로 여러 형태의 결과물을 바로 만들 수 있음(무료 플랜 기준 동영상 하루 3개).
  3. 자료 수집을 대폭 단축하는 7가지 크롬 확장프로그램: 웹페이지/유튜브를 클릭 한번으로 가져오거나(웹 임포터, 유튜브투노트북LM), 여러 탭/링크를 한번에 수집하거나(그레이빗, AI 사이드바), 전체 페이지를 이미지로 캡처하거나(고풀 페이지), 재생목록 100개 이상도 안정적으로 이관하고(유튜브 링크 소스 오토메이터), 노트북을 폴더별로 정리할 수 있어(북셰프 폴더 매니저) 수집·정리 시간을 대폭 줄임.

[도구 요약 표]

  1. 노트북LM 웹 임포터 - 클릭 한번으로 웹페이지/유튜브 가져오기, 오디오오버뷰-팟캐스트 동기화.
  2. 유튜브투노트북LM - 재생목록/채널 전체를 한번에 추출, 동영상 요약·하이라이트 추출.
  3. 그레이빗 - 텍스트 URL을 클릭가능 링크로 변환, 탭 선택 복사 지원(링크 여러개 한번에 수집 시 유용).
  4. 고풀 페이지 - 웹페이지 전체를 하나의 이미지로 저장(PNG/JPG/PDF), PPT·인포그래픽 제작 시 템플릿 캡처용으로도 활용 가능.
  5. 노트북 유튜브 링크 소스 오토메이터 - 재생목록 전체 제목·링크를 표 형식으로 추출, 중단 시 이어받기 지원.
  6. 노트북LM AI 사이드바 - 위키 등 다수 링크가 포함된 문서에서 필요한 링크만 골라 일괄 가져오기.
  7. 북셰프 노트북LM 폴더 매니저 - 노트북을 폴더별로 드래그앤드롭·검색·정렬로 관리.

[기타 활용 팁]

  • 공유 버튼에서 '노트북 액세스 제한됨'을 '링크가 있는 모든 사용자'로 변경하면 링크 공유만으로 보고서/오디오/동영상/퀴즈를 타인과 공유 가능.
  • 컬렉션 기능으로 여러 노트북을 주제별로 묶어 관리 가능.

[유의사항]

  • 중요한 연구나 주제의 딥 리서치 결과는 반드시 사실 관계를 직접 더블 체크해야 함.
  • 울트라 요금제는 시네마틱 동영상까지 제공되나, 프로 요금제와 무료 플랜은 동영상 생성 횟수가 제한적(무료 1일 3개 수준)임.
