빌더조쉬 - 카드뉴스 에이전트 팀 만들기 라이브 실습 (오르카+힉스필드)

영상 정보

  • 영상 URL: https://www.youtube.com/live/-1zFrs_TnoM?si=MfJQOOX66wGTY-8T
  • 구분: 클로드

요약

신간 "클로드 에이전트 협업의 기술" 출간 기념 라이브 실습. 카드뉴스·블로그·소셜포스팅을 하나의 브랜드 톤으로 자동 생성하는 마케팅 에이전트 팀을 처음부터 함께 구축하는 과정을 보여준다.

새 IDE 도구 "오르카" 소개: 커서·안티그래비티가 지나치게 단순해진 것과 달리, 오르카는 멀티 에이전트를 화면 분할로 병렬 실행할 수 있고 내장 브라우저에서 미리보기 화면의 UI 요소를 직접 클릭해 주석을 달면 그대로 클로드 코드에 피드백이 전송되는 기능이 강점이라고 소개한다(무료, 모바일 페어링도 지원).

세팅 순서: ① 컨텍스트 폴더에 브랜드 캐릭터 이미지와 참고할 카드뉴스 톤 이미지를 넣고, ② "마케팅 에이전트 팀을 만들고 싶어"라고 길게(의도를 최대한 풀어서) 명령하면 오케스트레이터(마케팅 디렉터)와 서브에이전트(카드뉴스 크리에이터, 블로그라이터, 소셜미디어라이터, 검수)가 자동 설계된다.

이미지 품질 문제와 해결: 클로드 단독으로 생성한 첫 카드뉴스는 밋밋한 텍스트 위주 결과물에 그쳤으나, .env에 오픈AI API 키를 넣고 GPT 이미지 2.0을 연동하도록 재지시하자 캐릭터와 디자인 완성도가 크게 향상되는 것을 실시간 비교로 보여준다. 클로드 코드 내에서 코덱스(Codex) CLI를 호출해 API 키 없이 이미지를 생성하는 방법도 소개한다.

영상화와 배포: 완성된 카드뉴스 한 장을 힉스필드(Hicsfield) MCP로 짧은 애니메이션 영상(캐릭터가 통통 튀는 효과, 5초, 건당 약 2~3천 원)으로 변환하는 과정을 시연한다. 이후 같은 세션에서 블로그 페이지, 전체 캠페인을 한눈에 보는 웹 대시보드까지 병렬로 생성했고, 버퍼(Buffer) API/MCP를 연동하면 소셜 미디어 예약 발행까지 자동화할 수 있다고 설명한다.

핵심 메시지: API 키 등 민감 정보는 반드시 .env에 저장하고 깃 저장소에는 올리지 말아야 하며(과거 실수로 270만 원 상당의 해킹 피해를 본 경험 공유), 결과물의 품질은 초반에 컨텍스트와 레퍼런스를 얼마나 충실히 입력했는지에 좌우된다는 점을 반복 강조한다.

키워드

오르카(Orca), 카드뉴스 자동화, GPT 이미지 2.0, 힉스필드 MCP, 마케팅 에이전트 팀
