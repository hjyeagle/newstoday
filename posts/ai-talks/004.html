한줄 요약

xAI 그록봇(Grok Bot)은 클라우드 PC에서 브라우저·앱을 직접 조작하는 상시 에이전트다. 말·커넥터뿐 아니라 화면 시연 학습과 봇 간 협업으로 일상 업무를 위임하는 10가지 활용을 시연한다.

그록봇이 다른 점

  • 클라우드에서 24시간 동작 (로컬 PC 상시 가동·설치 부담이 적음)
  • 자체 OS + 크롬 브라우저로 Computer Use 방식 UI 조작
  • OpenClaw·LMS 에이전트 대비 세팅이 단순하고 오류·딜레이가 적다는 체감
  • 시연 학습: 화면 녹화 → 스킬로 저장 → 반복 실행
  • 승인 규칙: 메일 발송·업로드 등은 확인 후 / 자동 실행 선택 가능
  • 요금: Super Grok 등 구독(영상 기준 월 ~$30대, Cursor 연동 시 사용량 분리 언급)

활용 방법 (영상에서 다룬 흐름)

  1. 봇 생성·페르소나 — +로 새 봇 → 이름·역할·루틴을 대화로 지정 (예: 매일 아침 스타일 추천)
  2. 아바타·업무 설명 정리 — 우측 패널에서 레이블·할 일·외형 편집
  3. 이메일(Gmail) — 커넥터로 연결, 인박스 정리·요약·반복 브리핑
  4. 캘린더·일정 — Google Calendar 연동, 일정 조회·등록을 비서로 위임
  5. 구글 드라이브 위키 — 폴더 구조 읽기, 문서 작성·이름 변경·이동·삭제까지 위임 (업무별 봇 분리를 권장)
  6. 커넥터 없는 웹 서비스 — 예: Simplenote 투두. 로그인된 브라우저에서 UI를 직접 조작해 유형·중요도·마감일 정리
  7. 플러그인/커넥터 확장 — Gmail, Drive, Calendar 외 Canvas·데이터 분석 등 연결 (국내 서비스는 아직 적을 수 있음)
  8. 시연 학습(Teach) — 「작업 가르치기」→ 녹화 → (예: Gemini로 이미지 생성 후 Gmail 전송) → 스킬화 후 재실행
  9. 팀장 봇 오케스트레이션 — 한 봇이 다른 봇들에게 지시·보고 취합 (전원 인사, 업무 목록 보고)
  10. 봇 간 파이프라인 — 예: 날씨 봇이 조사 → 팀장이 전달 → Threads 봇이 한국어 학습용 콘텐츠로 발행

실무 팁 (발표자 관점)

  • 가능하면 업무 단위로 봇을 나누는 편이 한 봇에 몰아주는 것보다 안정적
  • UX/UI 디자이너는 행정·문서·데이터 수집·분석을 먼저 위임하고, 기획·경험 설계에 시간을 쓰라
  • 위임할 것 / 인간이 쥘 것(미감·의도·목표)을 구분하는 능력이 중요해짐
  • 7일 무료 등이 있으면 짧게라도 직접 써 보며 경험치를 쌓을 것을 권장
