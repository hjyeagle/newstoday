헤르메스 에이전트 개념·설치·활용 총정리 (진한별의 AI연구소)

영상 정보

  • 영상 URL: https://youtu.be/DzHkeZ-fuUw?si=JhcFNc8dkR9GDrGt
  • 구분: AI창업

요약

[결론] 헤르메스는 노스리서치(깃허브 스타 18만 개+)가 만든 오픈소스 24시간 상주형 자율 에이전트로, 핵심은 '3층 메모리 구조'로 쓸수록 사용자를 학습해 진화하는 점입니다. PC, 맥미니, VPS 중 하나에 설치해 슬랙과 연동하면 바로 사용 가능하며, 자체는 무료입니다.

[핵심 근거]

  1. 3층 메모리 구조: 세션 컨텍스트(단기기억, 대화 보관) 이후 연구실(장기기억, 사용자 선호, 완료 작업 기록)을 거쳐 절차적 지식(5회 이상 반복된 작업을 자동으로 스킬로 생성)으로 이어지는 3단계로 작동하며, 이 구조 덕분에 스킬을 직접 만들어줌 필요 없이 반복 업무가 자동으로 개선됩니다.
  2. 비용·속도 최적화: 0.15.1 버전 기준 세션간 회상 속도가 4,500배 빨라졌고, 혼초(외부 메모리 프로바이더) 12개 레이어로 사용자를 추적하며, 1시간 프롬프트 캐시 내장으로 매번 파일을 다시 읽어야 하는 데서 발생하는 토큰 비용을 자동 절감합니다.
  3. 기존 도구와의 차이: 오픈클로가 '중앙 게이트웨이'형으로 쓸수록 메모리가 무거워지는 반면, 헤르메스는 에이전트 중심으로 더 가벼고 안정적으로 진화합니다. 클로드코드/코덱스는 PC가 꺼지면 종료되는 '작업 도구'이고, 헤르메스는 24시간 상주하며 반복 업무를 대신 수행하는 '설계 철학'이 다릅니다. 둘 다 쓰는 것이 최선입니다.

[설치 방법(3가지 옵션)]

  1. 집에 굴러다니는 남는 PC - 무료이지만 메인 PC 사용 시 보안 위험이 있어 반드시 별도 기기 권장.
  2. 맥미니 등 전용 기기 구매.
  3. VPS(가상 서버) - 24시간 상시 가동을 원한다면 가장 현실적인 선택.

[슬랙 연동 핵심 단계]

  1. 슬랙 개발자 사이트에서 앱 생성 후 권한(스코프) 9가지를 추가.
  2. 봇 토큰(xoxb-)을 터미널에 입력.
  3. 소켓 모드 활성화 후 앱 토큰(xapp-) 발급·입력.
  4. 사용자 멤버 ID와 헤르메스가 활동할 채널 ID를 링크에서 추출해 입력.
  5. 'hermes' 명령으로 에이전트 실행 후 'hermes gateway start'로 슬랙 연동 완료.

[주요 활용 예시]

  1. 크론 스케줄링: 매일 아침 9시 뿠티 포스팅 주제 5개 추천 등 반복 작업 예약.
  2. 개발: 에러로그 실시간 감지 및 수정 제안/직접 수정.
  3. 경쟁사 모니터링: 웹페이지/SNS 데이터를 구조화해 추출/감지.
  4. 핸드오프 기능: 카페/집/사무실 등 기기 간 세션 이관으로 맥락 끊김 없이 작업 지속.

[유의사항]

  • 사용 초기에는 진화 효과가 미미하지만, 1주/2주/1개월로 누적될수록 사용자와 업무를 학습해 결과물 품질이 크게 상승함(즉결효과를 기대하지 말 것).
  • PC에 직접 설치 시 보안 위험이 있으므로 업무용 메인 PC는 피하고 보안 관련 안내를 반드시 숙지해야 함.
