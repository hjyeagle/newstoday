AI와 나눈 이야기 모음 · 2026.09.15

구글 노트북LM 활용법 - 딥리서치·마크다운 문서·클로드코드 MCP 연동 (조현정 교사, KEIDA)

영상 정보

  • 영상 URL: https://youtu.be/Jx9JBRQFoK0?si=8kQAtimRi89XbV95
  • 구분: 제미나이

요약

[결론] 조현정 교사는 노트북LM을 '내 자료 기반으로만 답하는' 도구로 설명하며, 교과서를 마크다운으로 변환해 넣으면 AI가 구조를 더 잘 이해해 결과물 품질이 올라가며, 클로드코드와 MCP로 연동하면 리서치·강의안 작성·노트북 생성·팟캐스트/슬라이드 제작까지 명령 한 번으로 자동 실행된다는 점이 핵심입니다. 무료 계정도 노트북 50개, 노트북당 자료 50개까지 넣을 수 있어 충분합니다.

[핵심 근거]

  1. 재미나이 대비 차별점: 재미나이는 학습된 지식으로 답하여 할루시네이션이 많지만, 노트북LM은 사용자가 제공한 자료만을 근거로 답해 할루시네이션을 보완함. 파일·사이트·유튜브·구글드라이브 문서/시트/슬라이드 등 다양한 형식을 소스로 자동 추출함.
  2. 패스트/딥 리서치로 외국어 자료까지 확보: 출력 언어를 영어·일본어로 바꿔 트위터/레딧 중심 최신 자료까지 지정해 수집할 수 있고, 딥 리서치는 계획·수집·조사를 거쳐 보고서까지 자동으로 생성해 소스로 삽입됨.
  3. 클로드코드 + MCP로 수업 자동화: 200페이지 교과서 PDF를 클로드코드에 맡겨 마크다운으로 일괄 변환, 단원별 병렬 리서치 → 강의안 작성 → 검증 → 수정 → 노트북 생성·강의안 업로드·팟캐스트·슬라이드 제작까지 명령 한 번으로 병렬 자동 진행(노트북 공식 API는 엔터프라이즈 전용이라 개인은 사용 불가, 대신 MCP를 통해 개인 연동).

[실습 방법 요약]

  1. 노트북 LM에 교과서 PDF, 사이트, 유튜브 링크 등을 소스로 추가.
  2. '패스트 리서치' 또는 '딥 리서치'로 원하는 주제를 입력하면 관련 사이트를 자동 수집(딥 리서치는 보고서도 함께 생성).
  3. 오른쪽 스튜디오 패널에서 보고서 스타일(전략 가이드북/운영 혁신 보고서/기능 가이드 등)을 지정하거나 직접 프롬프트를 입력해 오디오오버뷰·슬라이드·마인드맵·플래시카드·퀴즈·인포그래픽을 생성.
  4. 중요 자료는 마크다운(# 등) 문서로 변환해 구조를 명확히 하면 AI가 더 잘 이해함(한글/PDF는 구조 파악이 약함).
  5. 슬랙에 오디오 파일 등록 후 이동 중에 들을 수 있고, 유튜브 공유 버튼으로 노트북 LM에 바로 담을 수 있음.

[추가 활용 사례]

  • 스탠퍼드등 대학의 공개 강의(수천개 단위) 리스트를 시트로 보유해 놓고 필요한 강의를 검색·선별해 노트북에 넣은 다음 한국어 오디오로 변환해 영어 리스닝이 약해도 내용을 이해.
  • 클로드코드에게 "노트북LM을 클로드코드로 연동하는 사례 조사해서 설치해달라"고 요청하면 MCP 연결까지 자동으로 진행되며, 비개발자도 AI에게 설치법을 물어보면서 따라할 수 있음.

[유의사항]

  • 무료/유료 차이는 노트북 개수와 노트북당 자료 개수(무료 50개/유료 300개 수준) 차이임.
  • 오디오·영상 생성은 10~20분 이상 시간이 걸리므로 기다림이 필요.
