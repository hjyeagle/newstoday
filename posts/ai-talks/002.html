클로드 코드 풀코스 2시간: 설치부터 AI 직원 만들기까지 (태오의 실행 비즈니스)

한줄 요약

코딩을 몰라도 클로드 코드를 'AI 신입사원'처럼 채용·교육해 첫 자동화부터 스킬·구글·옵시디언 연결, 토큰 관리, 에이전트 팀, 서버에서 도는 루틴까지 한 번에 익히는 입문 풀코스.

챕터별 요약

0:00 인트로

지난 6개월 영상 중 지금도 유효한 것만 골라 한 흐름으로 엮음. 처음이면 순서대로, 아니면 필요한 챕터만.

0:14 클로드 코드란? 뭘 준비하면 될까

  • 내 컴퓨터 폴더에서 파일을 만들고 실행하고 스스로 고치는 AI 작업 도구
  • 무료 불가, 최소 Pro. 사용량 많으면 Max 5배·20배
  • 터미널·VS Code·데스크톱 어디서 써도 됨

1:54 기초 · AI 신입사원 채용하기

  • 채용→작업공간→입사교육→업무지시→평가→추가교육 = 자동화 제작 과정
  • VS Code 확장 설치, 폴더 열기. Shift+Tab으로 모드 전환(확인 / 자동 수정 / Plan / Bypass)
  • 핵심은 코딩이 아니라 입력·처리·판단·출력으로 업무를 정리하는 능력
  • 예시: 매주 일요일 20시 유튜브 트렌드 PDF 리포트 → Gmail 발송 → 노션 누적
  • CLAUDE.md = 회사 매뉴얼. 워크플로우(SOP) · 에이전트(클로드) · 툴(파이썬) 3단계

10:52 자기 개선 루프

  • 에러 → 원인 분석 → 수정 → 재테스트 → 워크플로우 문서 갱신
  • API 키는 .env에
  • Plan 모드로 요구 사항을 쏟아내면 질문·웹검색으로 구체화
  • 정기 자동 실행은 MCP보다 파이썬 API 호출이 안정적
  • 컨텍스트 70% 무렵 /clear

17:18 MCP가 뭔가요

  • MCP = AI의 외부 서비스 연결 통로(앱스토어 비유). 여러 API 대신 서버 하나
  • MCP는 행동 능력, 스킬은 전문 지식(필요할 때만 로드)
  • 주의점 6: 정확한 기획 / 모르면 질문 / Plan 모드 / API 키 .env / 보안 리뷰 / 70%에서 클리어
  • 자동화는 도구가 아니라 '위임'의 문제

22:20 진짜 남은 스킬 6개

  1. 스킬 크리에이터 — 반복 업무를 전용 스킬로 제작, 계속 개선
  2. 슈퍼파워(Superpowers) — 브레인스토밍→계획→worktree→테스트→디버깅→리뷰, 14개 스킬
  3. 마케팅 스킬(Corey Haines) — 139개 아이디어, 제품·고객 맥락 공유. 한국 실정에 맞게 수정 필요
  4. UI UX Pro Max — 스타일 50·팔레트 161·폰트 57, AI 티 나는 디자인 방지
  5. I'm not AI(humanize-korean) — 의미 유지, 한국어 문체만 자연스럽게(80%까지)
  6. Remotion — 코드로 영상 제작, 반복 장면 템플릿화

37:44 보너스 · 케이브맨 (토큰 압축)

  • 장황한 응답을 압축해 출력 토큰 절감(Lite / Full / Ultra)
  • 도구를 늘리지 말고 반복 업무 자리에만 하나씩 붙이기

41:25 구글 연결 (GWS)

  • GWS CLI: 구글 워크스페이스 전체를 명령어로 제어
  • 자동 업데이트 · MCP 서버 내장 · 100개+ 스킬 · 보안 검사
  • 깃허브 주소를 클로드에 넣어 설치, Google Cloud 프로젝트·OAuth 동의·데스크톱 클라이언트 생성 후 로그인

47:02 이메일 자동 분류 · 문서 · 슬라이드

  • 30일 메일 249개 중요도 점수화, 저중요 읽음 처리, 뉴스레터 요약을 구글 문서로
  • 유튜브 영상 가이드를 서식 갖춘 문서로, 브랜드 가이드 반영 구글 슬라이드 12장 생성
  • 클로드는 눈이 없음 → 썸네일 캡처 스킬로 레이아웃 보정
  • 활용: 중요 메일 선별, 뉴스레터 주간 요약, 캘린더 알람, 오늘 할 일

55:40 옵시디언 연결 · 두 번째 두뇌

  • 옵시디언 = 로컬 마크다운 노트. 노션의 한계를 클로드 코드 결합으로 해결
  • 카파시 LLM 위키 패턴: 옵시디언=도서관, 클로드=사서, 위키=책꽂이
  • raw(외부 자료) → 내 사업 기준으로 걸러 wiki에 정리
  • 질문 2개로 구조·규칙 자동 생성, /ingest · /query · /lint
  • 시연: 대본 2,000줄 → 128줄 압축, 크로스링크 5개. 노션·메일·유튜브도 연결 가능

1:13:20 토큰 아끼는 습관 5가지

  • 분석 결과 토큰의 95.7%가 앞 대화 재독
  1. /context · /clear · /compact · /rewind(Esc 두 번). /compact는 지친 상태의 요약이라 부정확
  2. 60~70%에서 '결정/미정/다음 할 일' 정리 → 클리어 → 새 창에 붙여넣기
  3. CLAUDE.md 200줄 이하, 세부 규칙은 별도 파일(730→102줄, 9.4K→2.1K)
  4. PDF·HTML은 마크다운 변환 후 투입(Docling), Plan 모드 사용
  5. 단순 작업은 Haiku/Sonnet 서브 에이전트에 위임

1:26:45 에이전트 팀

  • 서브 에이전트=외주, 에이전트 팀=한 사무실에서 대화하는 직원들(메시지·공유 작업목록·상호 피드백)
  • 실험 기능이라 설정에서 활성화
  • 품질은 프롬프트에: 목표, 인원·모델, 역할, 워크플로우, QA 검증 에이전트
  • 시연: 프론트·백엔드·QA 3인 팀으로 우선순위·AI 멘토링 웹앱

1:35:10 팀 vs 서브 에이전트, 언제 뭘 쓸까

  • 기준: 서로 대화가 필요한가? 업무 80%는 서브 에이전트, 팀은 20%
  • 토큰 절약 7: QA는 Haiku / 테스트 환경은 개발자가 준비 / 파일 20개 미만이면 팀 금지 / 지시는 해당 에이전트에만 / 데이터 이름 통일 / DB는 Supabase 등 명시 / 전면 수정은 혼자

1:42:11 자는 동안 일하게 · Routines

  • 저장한 프롬프트를 Anthropic 서버에서 실행 → 노트북 꺼도 동작
  • 트리거: 스케줄(최소 1시간) · 깃허브 이벤트 · API
  • 주의: 작은 전용 저장소 연결, API 키는 환경 변수, 중간 질문 불가하니 구체적 지시+사전 테스트, 하루 실행 Pro 5회·Max 15회
  • 시연: 매일 8시 1인 기업 소식 10개를 카카오톡 나와의 채팅으로. 커넥터 누락·발송 승인 규칙 이슈를 거쳐 3번 만에 성공

1:55:03 마무리

자동화는 도구를 늘리는 게 아니라 내 시간을 되찾는 길. 오늘 딱 하나만 실행해 보기.

실무 포인트

  • 반복 업무 중 가장 단순한 것 하나부터 자동화
  • 새 기능은 Plan 모드로 시작, 검증 후 권한 위임
  • CLAUDE.md는 짧게, 컨텍스트 60~70%에서 정리 후 리셋
  • 스킬·도구는 필요할 때 하나씩만 추가
  • 정기 작업은 Routines(서버 실행)로 옮기기
