AI와 나눈 이야기 모음 · 2026.10.01

뉴스투데이 메인화면 리뉴얼 작업 정리

작업 개요

첨부 문서 「뉴스투데이_리뉴얼_2026_1001」의 요청에 따라 newstoday.co.kr 메인페이지(index.html)를 수정했습니다. 수정 기준 파일은 현재 사이트에 올라가 있는 index.html이며, 수정 전 파일은 index_before_1001.html로 백업했습니다.

1. 리뉴얼 요청 반영

  • 우측 상단 단락 삭제: "함께 읽고 나누는 비영리 디지털 공공광장" 문구와 글자 크기 조절 버튼을 모두 삭제
  • 타이틀 문구 변경: "실버세대가 AI와 소통하며 만들어 가는 이야기들…"로 수정(기존 설명 문장 삭제)
  • 메뉴 구성 변경: 세로 목록 대신 한 줄 3개씩, 총 3줄(9개)의 간결한 박스로 배치. 박스 안에서 바로 목록을 확인하며 하위 화면으로 넘어가지 않음
  • 페이지 표시 방식: POD(종이책)·전자책은 한 화면 5개, 나머지 메뉴는 3개씩 표시하고 박스 하단의 ‹ › 화살표로 이전/다음 페이지 이동
  • 하단 문구 교체: 기존 두 문구를 삭제하고 "Copyright 뉴스투데이 All rights reserved. 무단 전재 및 재배포 금지."로 대체

2. 메뉴 구성 (3 x 3)

  1. AI와 POD(종이책) 출간
  2. AI와 전자책 출간
  3. 사이버 동방예술관 (소개문 + 바로가기 새 창 링크)
  4. 비즈넷타임즈 오피니언 기고문
  5. AI와 나눈 이야기 모음
  6. 시니어 수익창출 방법
  7. 당뇨관리와 관련한 이야기
  8. 네이버 블로그 전체 글 (RSS 자동 수집 데이터 그대로 유지)
  9. 기타 모음 (현재 비어 있음)

3. 추가 수정

  • 도서 순서 변경: POD·전자책 모두 희망네비게이터, 광야의 발자국, 동방예술관 소장유물도록을 1~3번으로 올리고 "17년 그 길 위의 이야기들"은 4번으로 이동. 구매 링크도 제목과 함께 이동
  • 책 표지 배치: 타이틀 옆 빈 공간에 책 표지 6권(희망네비게이터, 광야의 발자국, 동방예술관 소장유물도록, 17년 그 길 위의 이야기들, 18년 그 길 위의 이야기들 2026년 1부·2부)을 나란히 배치. 표지를 누르면 POD 메뉴와 같은 교보문고 구매 페이지가 새 창으로 열림

4. 참고 사항

  • 표지 이미지는 assets/covers/cover1.jpg~cover6.jpg로 저장했으며, GitHub에 올릴 때 index.html과 함께 assets/covers 폴더도 올려야 합니다.
  • 표지는 번호 순서에 맞춰 저장돼 있어, 도서 순서를 다시 바꾸면 이미지 파일도 맞춰 바꿔야 합니다.
  • 네이버 블로그 자료(blogData)는 GitHub Actions의 scripts/sync-naver-blog.mjs가 자동 갱신하므로 형식을 그대로 두었습니다.
  • 새 항목은 index.html 안의 해당 배열에 { date, title, url } 한 줄을 추가하면 됩니다.
  • 수정 결과는 사이트 화면 캡처로 확인 완료되었습니다.
