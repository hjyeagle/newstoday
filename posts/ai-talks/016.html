AI 상품소싱 자동화 (Codex 활용)

영상 정보

  • 영상 URL: https://youtu.be/iWkcYh7r7lk?si=dq-zucbW2VlsK8Yf
  • 구분: AI창업

요약

[결론] ChatGPT Codex(월 20달러 플러스 요금제 내 무료)로 에이블리·하이버·지그재그·스마트스토어 4개 플랫폼을 6시간마다 자동 순찰하며, 신규진입/급상승/스테디셀러 3개 카테고리 x S/A/B 3등급 = 총 9개 상품을 추려 슬랙으로 보고하는 AI 소싱 직원을 무료로 구축 가능. 실제 결과물의 상품 적중률이 높았다고 저자는 평가함.

[핵심 근거]

  1. 규모: 4개 플랫폼 x 랭킹 100위 x 6시간마다 체크 = 1일 1,600개 상품 스캔(사람이 하면 불가능한 물량).
  2. 검증 로직(100점 만점): 복수 플랫폼 교차발견 25점 + 순위 상승세 25점 + 신상품 15점 + 네이버 데이터랩 검색량 교차검증 15점 + 자사몰 판매가능성(비브랜드) 20점.
  3. 준비물 3가지, 전부 무료: ①슬랙 채널 ②네이버 데이터랩 API(월 5만 건까지 무료) ③플랫폼별 랭킹 100 URL.
  4. 비슷한 디자인의 상품을 이름이 달라도 하나의 트렌드 군으로 묶어 인식.

[실행 방법 요약]

  1. 슬랙 전용 채널 생성.
  2. 네이버 개발자센터 가입 → API 허브에서 쇼핑인사이트 앱 등록 → API 키 발급(약 10분).
  3. 에이블리/하이버/지그재그 랭킹100 URL, 루핏 인기상품 URL 확보.
  4. 위 100점 채점 기준을 코덱스에 입력(API 키는 채팅창에 직접 노출 금지, 코덱스에 암호화 저장 방법을 물어 터미널에 입력).
  5. "4개 플랫폼을 6시간마다 순찰해 신규진입/급상승/스테디 x S/A/B 총 9개 상품을 슬랙으로 보고해줘"라고 지시하면 코덱스가 자동 구축.
  6. 이후 채팅창으로 "지금 조사해줘", "이 상품이 왜 S등급인지 설명해줘" 등 추가 명령 가능.

[유의사항]

  • 영상 속 등급/점수 기준은 저자가 7년간 쇼핑몰을 운영하며 경험적으로 세운 것으로, 실제 채택 시 자사 상황에 맞는 검증이 필요함.
  • 클로드 코드로도 구현 가능하나 비용 부담으로 코덱스를 택했다고 언급됨.

키워드

코덱스, 상품소싱, 쇼핑몰, 자동화, 슬랙, 네이버데이터랩, 트렌드분석
