동방예술관·뉴스투데이 홈페이지 제작 및 GitHub Pages 배포 — 대화 정리

2026년 9월 6일 · Claude와의 대화 정리

1. 오늘 진행한 작업 개요

newstoday.co.kr 홈페이지를 정적 사이트(index.html 1개 파일) 로 제작하고, GitHub Pages를 통해 무료로 배포하는 작업을 진행함. 기존에 확정된 7개 메뉴 사이트맵(PDF)을 기준으로 실제 동작하는 웹페이지를 완성함.

2. 완료된 작업

  1. index.html 제작
    • 첨부된 newstoday_사이트맵.pdf를 기준으로 7개 메뉴 구조 그대로 구현
    • 01/02(POD·전자책): 번호 클릭 시 새 창으로 온라인 서점 구매 페이지 연결
    • 03(사이버 동방예술관): PDF에서 도록 표지 이미지를 추출해 assets/dongbang-poster.jpg로 저장, 소개문 + hjyeagle.github.io/cyber_dongbang/ 새 창 연결
    • 04~07(오피니언 기고문 / AI 대화 모음 / 자료실 / Temp): 표(엑셀 형태) 로 구현, 데이터 배열(opinionData, aiTalksData, archiveData, tempData)에 한 줄만 추가하면 새 항목이 누적되는 구조
    • 모든 하위 화면에 "🏠 메인으로" 버튼 + 키보드 Home 키로 메인 메뉴 복귀 기능
    • 고령자·접근성 사용자를 고려해 큰 글자 크기 기본값 + 글자 크기 조절 버튼(가−/가/가+) 추가
  2. GitHub 저장소 정리
    • 사용하지 않는 저장소(weniv_blog 등) Settings → Danger Zone → Delete this repository 경로로 삭제 진행
  3. GitHub Pages 배포 설정
    • hjyeagle/newstoday 저장소가 비공개(Private) 상태라 Pages가 비활성화되어 있던 문제 확인
    • Settings → General → Danger Zone → Change visibility → Public 전환으로 해결
    • Settings → Pages → Source를 "Deploy from a branch"로 지정, main 브랜치 / (root) 폴더 저장 안내
    • 배포 완료 시 예상 주소: https://newstoday.co.kr/

4. 콘텐츠 갱신 방법 (담당자용 메모)

04~07번 메뉴에 새 항목을 추가할 때:

  1. GitHub에서 hjyeagle/newstoday 저장소 → index.html 열기
  2. 연필 아이콘(Edit this file) 클릭 → 브라우저에서 바로 편집
  3. 해당 데이터 배열(aiTalksData 등)을 Ctrl+F로 찾기
  4. 마지막 항목 뒤에 { date: "YYYY.MM.DD", url: "링크" } 형식으로 한 줄 추가
  5. Commit changes → Commit directly to the main branch
