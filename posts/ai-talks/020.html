24시간 AI비서 만들기 - Hermes Agent VPS 설치 실전 가이드 (시민개발자 구씨)

영상 정보

  • 영상 URL: https://youtu.be/fVSdfEviwsQ?si=5mYRA2UUTRWwrjTG
  • 구분: AI창업

요약

[결론] 헤르메스 에이전트는 처음부터 '24시간 비서'를 목표로 만들어져 텔레그램/슬랙 연동, 메모리, 크론 예약, 자동 스킬 생성을 기본 탑재하고 있어, 클로드코드/코덱스보다 비개발자의 '개인 비서' 용도에 더 적합합니다. 호스팅어 VPS(월 약 13,000원)에 도커로 5분 내 배포 가능하며, 모델은 코덱스(챗GPT 구독)부터 시작하는 것을 추천합니다.

[핵심 근거]

  1. 출발점이 다름: 클로드코드/코덱스는 내가 책상에 앉아서 직접 쓰는 작업도구로 24시간 비서로 커스텀하려면 부담이 큰 반면, 헤르메스는 처음부터 이 용도로 설계되어 텔레그램/슬랙 연동과 메모리 기능이 기본 탑재되어 있으며, 오픈소스라 모델 종속 없이 작업별로 다른 모델(예: 글쓰기는 오퍼스 4.7, 코딩은 GPT-5.5)을 동시 활용할 수 있습니다.
  2. 설치 비용과 속도: 호스팅어 VPS KVM2 기준 월 약 13,000원(2년 약정 기준)으로, 도커 매니저에서 원클릭 배포 템플릿을 선택하고 퀵 셋업을 진행하면 텔레그램/슬랙 연동까지 짧은 시간 내에 완료됩니다.
  3. 자율 정체성 형성: '솔 MD' 파일에 이름/성격/역할을 설정하고, 대화를 통해 자동으로 생성되는 memories/user.md(사용자 정보)와 memory.md(장기기억)로 지속적으로 학습합니다. 또한 5회 이상 반복된 작업은 요청 없이도 스스로 스킬로 자동 생성됩니다(예: 리서치 요청 후 'singletopic research brief' 스킬 자동 생성).

[설치 절차 요약]

  1. 호스팅어 VPS 구매(KVM2, 아시아 리전, 우분투 24.04 LTS) 시 도커 매니저 옵션 함께 체크.
  2. 도커 매니저에서 원클릭 디플로이 → 헤르메스 템플릿 선택 → 어드민 계정 설정.
  3. 컨테이너 터미널에서 퀵 셋업 → 모델 프로바이더(코덱스 추천) 로그인 코드 입력 → 메시징 플랫폼(텔레그램/슬랙) 선택.
  4. 텔레그램: 볷파더에서 봇 생성 → 토큰 발급 → 유저인포봇으로 내 아이디 확인후 허용 유저로 등록(불특정 다수 응답 방지).
  5. 슬랙: api.slack.com/apps에서 앱 매니페스트 JSON을 붙여넣어 권한·이벤트 구독을 한 번에 설정후 워크스페이스에 설치.
  6. VS Code Remote-SSH로 컨테이너 내부에 접속해 솔 MD, memories 폴더 등 파일 구조를 직접 확인·수정 가능(보안 강화 시 테일스케일 VPN 연동도 가능).

[비서 설계 채택법]

  1. 솔 MD에 이름/성격/역할/말투를 먼저 지정.
  2. '나에 대해 궁금한 것 5가지 이상 질문해달라'고 요청해 사용자 정보를 최대한 많이 입력(실제 직원 오리엔테이션하듯 상세히).
  3. 간단한 업무부터 함께 프로세스를 논의하며 하나씩 설정.
  4. 프로세스가 정형화되면 자동 생성된 스킬을 반복 사용하고, 주기적 자동화(크론)까지 프롬프트로 요청해 완성.

[유의사항]

  • 파일 저장 위치나 타임존(UTC vs 한국시간) 등 세부 설정은 초기에 의도와 다르게 실행될 수 있으므로 피드백으로 교정해야 함.
  • 민감한 자료를 외부 클라우드 VPS 대신 로컬에만 두고 싶다면 맥미니 등 별도 기기 구매가 대안임.
